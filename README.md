# 샤프트 외경(OD) 측정 — 이다겸 실험 저장소

> 이 저장소는 팀 파이널 프로젝트(백라이트 사진으로 샤프트 외경 Ø20.02 ±0.01mm를 재는 과제)의
> **일부**입니다. 팀 전체 코드가 아니라 **이다겸 개인이 수행한 실험만** 모아 둔 저장소이며,
> 팀원(선행 개발자·팀장)의 측정 엔진·분석 코드는 여기 포함되어 있지 않습니다(각 실험 문서에서
> "팀원A"·"팀원B"로 비교 대상으로만 언급됩니다).

## 과제 배경

백라이트로 찍은 샤프트 실루엣 사진에서 위·아래 경계를 찾아 지름을 재고, 공차
±0.01mm(≈0.27px, 1px ≈ 0.037mm) 안에서 양품/불량을 가려내는 것이 목표입니다.

## 지금까지의 결론 (2026-10-16 기준)

**현재 데이터(130장, 독립 셋업 13개)로는 "사진 → mm" 보정식도, 엣지 학습 모델도
평균 찍기(정상 시편 평균값을 그대로 답하는 방식, MAE 5.78µm)를 확실히 이기지 못했습니다.**
원인은 측정 방법이 아니라 사진마다 달라지는 촬영 조건(카메라 이동, 초점, 시편 놓임)의
변동이 찾으려는 신호보다 크기 때문입니다.

| 단계 | 결론 |
| --- | --- |
| 1st (YOLO 모델 비교) | 6개 모델 비교 결과·캘리브레이션 수치는 `results/` CSV·JSON 참고 |
| E1–E6 (측정·보정) | 보정식 확정 불가. 경계 정의는 cross50/moment 후보로 좁힘 |
| E2 (증강) | 안전한 변형은 일부뿐(어둡게·대비 축소·소폭 평행이동) |
| E7 (엣지 학습 프로토타입) | teacher(cross50) 복제까지는 성공, GT 없어 정확도는 미확인 |
| E10 (실측 지름 파인튜닝) | 8개 변형 전부 평균 찍기를 이기지 못함 → "셋업 잡음 흡수"로 판단 |

자세한 수치와 근거는 [`experiments/2nd/README.md`](experiments/2nd/README.md)와
각 실험 폴더의 `README.md`에 있습니다.

## 다음 단계

모델을 더 밀어붙이기보다 **촬영 환경 자체를 바꿔야 한다**는 결론에 따라, 3차 촬영에서는
- 지름을 아는 핀게이지 세트를 정답(GT)으로 함께 촬영
- 같은 시편 재장착 반복 촬영으로 "장착 변동" 자체를 측정
- 베이스판에 폰·벽·V블록을 고정해 조건 재현성 확보

를 준비하고 있습니다. 계획은 [`experiments/3rd/setup/README.md`](experiments/3rd/setup/README.md)에
정리했습니다.
