# E13 거칠기 분석 재현·조정 — 실행 전 고정 규칙 (사전 등록)

- 작성: 2026-10-27. E13의 지표(희연님 방식 엣지 산포의 재현값, 한 장 산포의 성분 분해, E13 상관표)는 **계산하지 않은 상태**에서 작성했다.
- 이 문서의 규칙은 결과를 본 뒤 바꾸지 않는다. 바꿔야 하면 부록에 "사후 변경"으로 날짜·이유와 함께 적는다.
- 새 측정·재촬영은 없다. 원본 사진도 디코딩하지 않는다. **E11 캐시와 10/21 CSV만** 쓴다.
- **E13은 거칠기 가설을 새로 검정하는 실험이 아니다.** E11의 결론은 바꾸지 않는다. E13의 목적은 같은 엣지를 본 두 분석(희연님 분석, E11-A)이 왜 반대 부호를 내는지 설명하는 **재현·조정**이다. 모든 결과는 탐색·서술이며 "유의"라는 표현을 쓰지 않는다.

## 3. 지표 정의

- **점 추출**
  - `pts`(희연님 방식 근사): ROI를 31점으로 나눈 x_k = 8008 + k × 272/30 (k = 0\~30) 중 창 안의 점. 창 H에서는 k = 10\~23, 14점(x ≈ 8098.7\~8216.5). y는 그 이미지의 열 값을 선형 보간한다.
  - `cols`: 창 안의 모든 열(2px 간격).
- **추세 제거**
  - `none`: 추세를 빼지 않는다.
  - `poly1`: 최소제곱 직선을 뺀다.
  - `poly2`: E11 `robust_fit`과 같은 강건 2차(1차 적합 → |r| < 4 × 1.4826 × MAD 밖 제외 → 2차 재적합). 잔차는 최종 적합식을 모든 점에서 뺀 값(E11 부록 규칙과 같음). E13-2·E13-4에서 쓴다.
- **산포 지표**(d = 추세 제거 후 값)
  - `MAD_med` = median(|d − median(d)|) — 표준적인 중앙값 절대편차
  - `MAD_mean` = mean(|d − median(d)|) — 중앙값 기준 평균 절대편차(희연님 설명 "중앙값의 평균"의 가능한 해석)
  - `STD` = 표준편차(ddof = 1), `Range` = max − min
  - 모두 px와 µm(× 26.092)로 적는다.
- **`CV_diam`**(희연님 "Raw CV"의 근사, 정의 미확인): 이미지마다 D = 창 안 열들의 median(y_bot − y_top), 시편별 10장 D의 std/mean × 100(%).
- **대표 MAD 정의:** E13-1에서 재현된 정의(4절 규칙). 재현된 것이 없으면 `MAD_med`.

## 4. E13-1 희연님 수치 재현

- 대상: NO2·NO9·NO10의 1번 이미지, 하단, 창 H.
- 변형 8가지 = {MAD_med, MAD_mean} × {pts, cols} × {none, poly1}. 각 변형에서 STD·Range도 함께 계산한다.
- **재현 판정(고정):** 한 변형에서 NO2·NO9·NO10의 MAD가 모두 희연님 값(0.573·0.811·0.930px)의 **±25% 안**이고 순서 NO2 < NO9 < NO10이 같으면 "재현".
  - 재현된 변형이 있으면 최대 상대오차가 가장 작은 변형의 MAD 정의를 **대표 MAD 정의**로 정한다(같으면 MAD_med). 그 변형을 E13-3의 **재현 행**으로 쓴다.
  - 없으면 "엣지 추출 방식 차이로 수치 재현 불가"라고 적고, 대표 MAD 정의 = MAD_med, 재현 행 = (H, pts, none, MAD_med)로 둔다.
- 보조(서술): 11시편의 CV_diam(창 H, 10장)과 희연님 Raw CV 표를 Spearman ρ와 크기 비(중앙값)로 비교한다. NO9는 희연님이 이상값을 뺐으므로 ρ를 NO9 포함·제외 둘 다 낸다.
- 우리 엣지는 3열 평균·평활된 cross50이고 희연님 엣지 검출 방법은 모른다. 수치가 정확히 같을 수 없다는 점을 결과에 함께 적는다.

## 5. E13-2 한 장 산포의 성분 분해 (핵심)

**질문:** 1번 이미지 한 장의 하단 엣지 산포가 (1) 시편 고유 표면 성분, (2) 시편과 무관한 고정 패턴, (3) 장마다 다른 잡음 중 무엇으로 이루어졌는가.

- 주 설정: 창 C, 하단, `poly2`, `cols`. 보조: (창 C, poly1), (창 H, poly2).
- 시편 p의 이미지 i마다 잔차 r_i(열 방향)를 만든다.
  - **V1_p** = 10장 평균 var(r_i) (ddof = 1)
  - **R_p** = 같은 시편 이미지 쌍(i ≠ j) cov(r_i, r_j)의 평균, 두 이미지의 공통 열에서 계산
  - **F_p** = 다른 시편 q의 각 q에 대해 이미지 쌍(i ∈ p, j ∈ q) cov의 평균을 구하고, q들에 대한 중앙값
  - **S_p** = R_p − F_p (시편 고유), **N_p** = V1_p − R_p (장마다 다른 잡음)
  - 몫: S_p/V1_p, F_p/V1_p, N_p/V1_p. S_p가 음수여도 원래 값을 적는다.
- **열 맞춤 규칙:** 보간하지 않는다. 같은 절대 x만 짝짓는다. x 격자 홀짝이 다른 이미지끼리는 공통 열이 없으므로 쌍에서 뺀다(E11과 같은 처리). NO8 안에서는 같은 홀짝끼리만(짝 4장 6쌍 + 홀 6장 15쌍 = 21쌍). 공통 열 30개 미만인 쌍은 뺀다. 쌍 개수를 기록한다.
- **E11과의 정합 점검**(E13-0에서 실행): 창 = 각 이미지의 캐시 전체 열, 윗엣지, poly2로 R_p, F_p를 계산해 E11 `S_within_med`, `S_cross_med`와 비교한다. 기대치: 시편 간 Spearman ≥ 0.8, 비(R/S_within, F/S_cross)의 중앙값 0.8\~1.25. 벗어나도 정의를 바꾸지 않고 기록한 뒤 진행한다(split-half 5장 평균과 단일 이미지 쌍은 기댓값이 같지만 표본 구성이 다르다).
- **주성분 판정(고정):** 11시편 몫의 중앙값이 0.5 이상인 성분을 "주성분"이라 부른다. 없으면 "혼합".
- **연결(서술, 양측 순열 p):**
  - 시편 간 Spearman: 1번 이미지 MAD(같은 창·추세 제거, 대표 정의) vs √max(S_p, 0), √F_p, √N_p
  - 각 성분(√max(S,0), √F, √N) vs Rq, Ra, Rz, 촬영 순서

| C_rev-cols-poly1-10 | C_rev | cols | poly1 | 10장 지표의 중앙값 |

- 지표: 대표 MAD, STD, Range. 그리고 CV_diam(창 H, C).
- 통계: Ra·Rq·Rz 각각과 Spearman ρ, **양측** 순열 p(10000회, 시드 42, p = (초과 횟수 + 1)/(10000 + 1), 초과 = |ρ_perm| ≥ |ρ_obs|), 참고용 Pearson r(희연님 값과 비교), 지표와 촬영 순서의 Spearman ρ. n = 11.
- **안정군 행:** 희연님 안정군 목록을 E13-3 실행 전에 받으면 그 목록으로 재현 행·대표 행을 한 번 더 낸다. 못 받으면 내지 않고 기록한다. 기준을 추측해서 만들지 않는다.
- 보고서 첫 줄의 대표 수치 = **대표 행, 대표 MAD vs Rq.**

## 7. 결론 문장 (고정)

- 정의
  - "양의 상관 재현" = 재현 행에서 Pearson r(Rq, 대표 MAD) ≥ +0.30 (n = 11, 전체 시편)
  - "시편 고유 성분과 Rq" = E13-2 주 설정에서 Spearman ρ(√max(S_p, 0), Rq)
- 결론 문장(셋 중 하나를 **그대로** 쓴다)
  - **A.** 양의 상관 재현 + 시편 고유 성분과 Rq ρ ≤ 0 → "희연님의 양의 상관은 우리 엣지 데이터에서도 보이지만, 그 상관은 시편 고유 표면 성분이 아니라 한 장 산포의 다른 성분에서 나온다. 거칠기보다 측정 쪽 변동이 원인일 가능성(탐색, n = 11)."
  - **B.** 양의 상관 미재현 → "희연님의 양의 상관은 우리 엣지 데이터(전체 11시편)로 재현되지 않는다. 차이는 엣지 추출·창·시편 선택의 차이로 보인다(탐색, n = 11)."
  - **C.** 양의 상관 재현 + 시편 고유 성분과 Rq ρ > 0 → "한 장 산포와 시편 고유 성분 모두 Rq와 같은 방향이다. E11-A 하단 결과(ρ −0.58)와 상충하며 원인은 이 데이터로 판단 불가(탐색, n = 11)."
- 덧붙일 문장
  - 주성분: "1번 이미지 하단 엣지 산포의 주성분은 ○○(시편 고유 / 고정 패턴 / 장마다 다른 잡음 / 혼합)이다(11시편 몫 중앙값 S ○○, F ○○, N ○○)."
  - 항상: "E11의 결론(주 가설 문장 2번)은 바뀌지 않는다. E13은 새 검정이 아니라 재현·조정이다."

## 8. E13-4 E11-A 하단 재계산 (사후 민감도)

- **E11 결과(하단 보조 ρ −0.58)를 본 뒤의 재계산**이다. 팀 기준(하단, 거칠기 측정 구간)에 맞춘 버전을 보고서에 한 줄 넣으려는 용도이며 결론 문장에 쓰지 않는다.
- 설정: 하단, 창 C(주)·C_rev(보조), poly2. E11-A 절차를 그대로 쓴다: split-half 126가지, 고정 패턴 50가지(시드 42), NO8 보간 규칙(E11 부록), 1단계(고유 성분 시편 ≥ 6/11)·2단계(단측 순열 10000회).
- 거칠기: Rz(E11 주 지표)와 Rq(멘토 조언) 둘 다. 끝 3열 제외 변형도 함께 낸다.
- 결과는 E11 PREREG 3.6절 결론 문장 1\~3번 중 무엇에 해당하는지로 적되, 앞에 "사후 민감도(E11 결과를 본 뒤)"를 붙인다.

## 10. 보고에 반드시 적을 한계

- 시편 11개, 한 세션, 거칠기는 시편당 1회·1위치 측정. 같은 시편의 업체 첫 측정 3개와 재측정이 다르다(NO10 Rz 8.1 → 16.4µm). 거칠기 라벨 자체가 측정 위치에 따라 흔들린다.
