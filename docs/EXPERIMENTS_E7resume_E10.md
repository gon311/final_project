## 0. 배경

### 0.1 멘토 피드백 요지 (2026-10-15)
- 하단 빛 띠: OpenCV가 그림자·선을 경계로 판단해 실린더 끝을 제대로 인식하지 못하는 것으로 봄. 조명을 바꿔도 표면이 반사를 잘하는 재질이라 효과가 제한적일 수 있음. 배율을 먼저 시도하라고 권함.
- 하단의 뚜렷한 검은 선을 실제 외곽선으로 인지하도록 학습할 것을 제안:
  1. 기존 모델에 dense layer를 하나 더 추가해 학습
  2. One-class learning
  3. 실제 실린더 값을 레이블(파일명)로 학습 데이터 생성
  4. 가이드핀(오른쪽)과 실린더(왼쪽)를 바운딩 박스로 구분해 학습
  5. 핀과 실린더의 축이 일치하면 각 영역을 crop해 레이블을 묶어 학습
  - 원리: 이미지에 실제 답을 주고, 그 답에 맞는 영역 특징을 모델이 스스로 학습하게 한다. 범용 모델은 도메인 최적화가 안 돼 있으니 도메인 데이터로 학습해야 한다.
- 사진은 최소 100장, PyTorch 증강으로 증폭.
- "One-class"의 의미(측정 전 품질 게이트인지, 측정 학습 방법인지)는 멘토에게 확인 중이다. **이 지시서는 1·3번과 4·5번 일부만 다룬다.**

### 0.2 멘토 제안을 이 지시서에 옮긴 방식

| 멘토 제안 | 이 지시서 |
|---|---|
| 기존 모델에 dense layer 추가 | E7 heatmap 모델의 헤드(변형에 따라 마지막 conv 블록까지)만 파인튜닝 |
| 실측값을 레이블로 | 이미지 단위 **지름 손실**로 학습 (E10) |
| 답에 맞는 영역을 모델이 스스로 학습 | 파인튜닝 뒤 하단 엣지가 **어느 단으로 옮겨 갔는지** 기록 (E10 6단계) |
| 핀/실린더 구분 | 핀 비율 환산 변형(V2)에서 이미지별 핀 px를 함께 사용. 핀 crop 자체를 학습하는 것은 범위 밖 |
| 증강으로 증폭 | E2b에서 아직 검증하지 않은 증강 3종을 판정한 뒤 허용 목록 확장을 제안 |

### 0.3 왜 "지름 손실"인가
다음 촬영의 정답(GT)인 공칭 핀게이지 세트도 **엣지 위치가 아니라 지름**이다. 상·하단 엣지가 각각 어디인지는 GT가 생겨도 여전히 모른다. 그래서 GT가 오면 어차피 "엣지 모델을 지름 손실로 학습"하는 구조가 필요하다. E10은 이 구조를 10-08 데이터로 먼저 만들고, 멘토 제안이 이 데이터에서 실제로 무엇을 하는지 수치로 확인한다.

### 0.4 미리 정해 두는 예상과 해석 기준
- 정답은 정상 시편 10개(독립 셋업 11개, 학습 fold당 9시편)뿐이다. 시편 간 실측 차이(약 0.5px)보다 셋업 변동(시편 간 범위 3.4px, 초점·카메라 이동에 따른 배율 변화 최대 약 0.5%)이 훨씬 크다. 평균 찍기 기준선(E6: 시편 LOO MAE 5.8µm, 최대 12.7µm)을 이기지 못할 가능성이 높다. **이기지 못하면 그것이 결과다**("이 데이터에서는 실측 레이블이 엣지 학습에 쓸 정보를 담지 못함").
- 모델이 지름을 맞추려고 엣지를 크게 옮기면(열별 이동 중앙값 > 1px) 셋업 잡음을 외운 것으로 본다.
- 하이퍼파라미터(λ, 학습 범위, 환산 변형)는 **LOSO MAE로 고르지 않는다.** 모든 변형을 그대로 보고한다.
- 같은 셋업의 10장은 독립 표본이 아니다. 유효 표본 수는 시편 수(fold당 9)다.

## E10. 실측 지름 파인튜닝 (멘토안 검증 + 다음 촬영 GT 학습 구조)

- **목적**
  1. 멘토 제안(기존 모델 + 학습 레이어, 실측값 레이블)을 우리 구조로 구현해, 평균 찍기와 teacher 대비 성능을 수치로 확인한다.
  2. 실측 레이블이 하단 엣지를 어느 단으로 끌고 가는지 보고, "어느 단이 실제 외곽인가"에 대한 간접 증거를 얻는다.
  3. 다음 촬영 GT(공칭 핀게이지)로 그대로 다시 돌릴 수 있는 스크립트를 만든다.

- **입력**
  - `cache/E7_edge1d/profiles.npz`(없으면 `E7_edge1d/build_cache.py`로 재생성). 필드: `top_profiles`·`bot_profiles`(89px), `top_label`·`bot_label`(teacher 오프셋), `top_center`·`bot_center`, `x`, `filename`, `bundle`, `specimen`, `role`, `focus`, `pin`.
  - 실측 mm: 분류표 `실측mm` 열(`E6_calibration/results/values_by_image.csv`에도 같은 값이 있다).
  - 이미지별 핀 px: `E6_calibration/results/values_by_image.csv`의 `pin_cross50_px`(E5에서 정한 핀 상대 위치 측정).
  - E7 코드 `model.py`, `augment.py`, `train_eval.py`의 `train_net`·`predict`는 import해서 재사용한다. **E7 파일은 수정하지 않는다.** 필요하면 E10 폴더에 래퍼를 둔다.
  - E6 `calibration.py`의 `fit_const`·`fit_linear`·`fit_fixed_scale`과 `run_calibration.py`의 핀 비율 방식을 참고하거나 import한다.

- **방법**
  1. **fold별 사전학습(누수 방지).** `E7_edge1d/checkpoints/*.pt`는 정상 10시편 전체로 학습한 최종 모델이라 held-out 시편의 프로파일을 이미 봤다. **시작점으로 쓰지 않는다.**
     - 시편 단위 LOSO 10 fold마다 E7과 같은 설정(heatmap 헤드, 상단 raw·하단 raw, 200 epoch, 시드 42, E7 허용 증강)으로 teacher 사전학습을 다시 한다.
     - 체크포인트는 `cache/E10_diam_finetune/pretrain_<시편>_{top,bot}.pt`에 저장하고 커밋하지 않는다. 파일이 이미 있으면 건너뛴다.
     - NG 평가용 "정상 10시편 전체" 모델도 같은 방식으로 하나 만든다(E7 최종 체크포인트와 같은 설정이면 재사용해도 된다. 재사용 여부를 README에 적는다).
     - sanity check: fold별 teacher MAE가 E7 `results/cv_metrics.csv`의 heatmap 값과 같은 범위인지 확인한다.
     - 하단 flipped 변형은 생략한다(E7에서 heatmap raw와 차이가 0.005px).
  2. **지름 조립.** 이미지 i, 열 j에서 `d_ij = (bot_center + bot_pred) − (top_center + top_pred)`. 이미지 지름 `D_i`는 열 `d_ij`의 절사평균(상·하위 10% 제외)으로 한다(미분 가능해야 한다). teacher 라벨로 같은 계산을 한 `D_i^teacher`도 만들고, E1 `measure_bearing`의 직선적합 지름과의 차이 중앙값을 README에 적는다.
  3. **환산 변형 (둘 다 돌린다)**
     - **V1 물리 스케일:** `pred_mm_i = 0.0367 · D_i + c`. `c`는 학습 스칼라이고, 초기값은 학습 fold에서 `D_i^teacher`로 구한 최소제곱 값이다.
     - **V2 핀 비율:** `pred_mm_i = 10 · D_i / pin_px_i + c`. 묶음 1(P1)은 학습에서 뺀다(E6와 같은 처리).
     - 손실은 `Huber(pred_mm − 실측mm)`이고 µm 단위로 계산한다. 배치는 이미지 단위로 묶는다(이미지 한 장의 모든 열을 한 번에 넣어 `D_i`를 만든다).
  4. **학습 범위(자유도) 변형 (둘 다 돌린다)**
     - **H:** heatmap 헤드(1×1 conv)만 학습하고 백본은 고정한다. 멘토가 말한 "dense layer 하나 추가"에 가장 가까운 설정이다.
     - **H+B:** 마지막 conv 블록과 헤드를 학습한다.
     - teacher 복제 유지 항 `λ · mean|pred − pretrain_pred|`(px)을 더한다. λ ∈ {0, 1} 두 값을 고정해 둘 다 보고하고, MAE로 고르지 않는다.
     - Adam lr 1e-4, 50 epoch, 시드 42. **증강은 쓰지 않는다**(E2b 결과가 나온 뒤 별도 변형으로 추가할지 사용자와 정한다).
     - 결과적으로 변형은 V{1,2} × {H, H+B} × λ{0,1} = 8개다.
  5. **평가 (중첩 LOSO가 핵심)** — fold k(held-out 시편 k)마다:
     - 파인튜닝과 `c`는 **학습 9시편으로만** 맞춘다.
     - held-out 시편 k 이미지의 `pred_mm`을 계산한다(모델 직접 예측 경로).
     - 같은 fold 모델로 학습 9시편의 `D_i`를 다시 계산해 E6 캘리브레이션 방식(0 평균 찍기, 2 전체 선형, 3 물리 스케일 + 오프셋, 4 핀 비율 선형)을 **fold 안에서** 맞추고 k를 예측한다("모델 px + 기존 캘리브레이션" 경로).
     - **out-of-fold px만 모아 E6 `run_calibration.py`에 통째로 넣지 않는다.** 그러면 학습 시편들의 px가 서로 다른 fold 모델에서 나와 섞인다.
     - NG1·NG2는 정상 10시편 전체로 파인튜닝한 모델로 **평가만** 한다. 판정과 방향을 함께 적는다(규칙 4·11).
     - 지표: 시편 LOO MAE·최대(µm), 평균 찍기 대비 차이, 정상품 오판정 수, NG 판정·방향, 셋업 내 σ(µm, NO7 포함·제외, 규칙 12), teacher 대비 열별 엣지 이동량(상·하단 각각 중앙값·95퍼센타일, px), fold별로 평균 찍기를 이긴 횟수.
     - 표 첫 줄은 평균 찍기(규칙 10), 둘째 줄은 teacher(사전학습 모델 그대로, 파인튜닝 없음)다.
  6. **하단 단 이동 진단**
     - 하단 프로파일마다 `shaftlab.multistep.find_peaks_subpixel`(E3과 같은 설정)로 단 위치를 구한다.
     - teacher, 사전학습 예측, 파인튜닝 예측이 각각 위치 순서상 몇 번째 단에 가장 가까운지 센다. 가장 가까운 단과 2px 넘게 떨어지면 `ambiguous`로 표시한다.
     - 시편·초점(F1/F2/F3)별 점유율 표를 만든다.
     - 판단 기준: 실측 레이블이 하단 엣지를 **셋업과 관계없이 같은 단으로 일관되게** 옮기면 "외곽 후보에 대한 간접 증거", **셋업마다 다른 방향으로** 옮기면 "셋업 잡음 흡수"다. 상단은 이동량만 기록한다.
  7. **해석 규칙 (미리 고정, 결과를 본 뒤 바꾸지 않는다)**
     - 아래 세 조건을 모두 만족하면 "실측 레이블이 정보를 담고 있을 가능성. 다음 촬영에서 재확인"으로 결론 낸다.
       - 평균 찍기 대비 MAE가 3.4µm 이상 낮다(E6 동일 장착 반복성 바닥, `E6_calibration/results/within_mount_repeatability.csv`).
       - 10 fold 중 7 fold 이상에서 평균 찍기보다 낮다.
       - 열별 엣지 이동 중앙값이 1px 이하다.
     - 그 밖의 경우는 "이 데이터에서는 실측 레이블 학습이 셋업 잡음을 넘지 못함"으로 결론 낸다.
     - 어떤 경우든 "13개 셋업, 재장착 반복 없음"이라는 한계를 함께 적는다(규칙 8).
  8. **다음 촬영 대비 일반화**
     - 스크립트 입력을 인자로 받는다: `--profiles`(npz), `--meta`(분류표 CSV. 필수 열: 파일, 묶음, 시편, 역할, 실측mm), `--pin-col`(선택), `--label-source {micrometer, gauge}`.
     - 공칭 핀게이지 행은 `역할 = gauge`로 받고, `실측mm` 자리에 공칭 지름을 넣는다. LOSO 그룹은 "물체 ID"(핀게이지는 지름별 하나, 샤프트는 시편별 하나)로 한다.
     - 10-08 데이터에는 gauge 행이 없으므로 **코드 경로만** 만든다. 작은 합성 메타 CSV로 경로가 끝까지 도는지만 테스트하고, 합성 수치로 어떤 결론도 내지 않는다.
     - px 상수(창 크기, 절사 비율 등)는 설정값으로 둔다(규칙 14).

- **Codex 리뷰가 지적하기 쉬운 부분 (미리 지킬 것):** fold별 사전학습(누수 방지), 중첩 캘리브레이션, NG 시편 미사용, λ·변형을 MAE로 고르지 않음, 같은 셋업 10장은 독립이 아님(유효 n = 9), 해석 규칙을 결과 전에 고정.
