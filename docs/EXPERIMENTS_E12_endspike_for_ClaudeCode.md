## 2. E12-A NO1 크롭 프레임 (출력 좌표 vs 센서·장면 좌표)

**아이디어.** NO1은 중앙 1:1 크롭이라 센서 한 열이 출력의 x − 2408 열로 간다. 스파이크가 센서·렌즈·장면에 붙어 있으면 NO1에서 **x ≈ 8265 − 2408 = 5857**에, 출력 이미지 좌표(JPEG·ISP 후처리의 열 위치)에 붙어 있으면 **x ≈ 8265**에 나온다. (장면과 센서는 이 단계에서 가를 수 없다. 카메라가 안 움직였기 때문이다. E12-B, E12-E에서 다룬다.)

1. NO1 본시험 10장의 윗엣지를 x = 1000\~9500(엣지가 보이는 범위, 사전 스캔 확인됨)에서 열마다 추적한다. 추적은 이전 열의 엣지 y ± 30px 안에서 교차를 찾는 방식으로 하고, 못 찾는 열은 NaN.
2. 같은 방법으로 줌 1.00 시편 5개(NO3·NO5·NO7·NO9·NO10, 각 5장)를 x = 6000\~11000에서 추적해 8265 스파이크가 재현되는지 먼저 확인한다(양성 대조).
3. 스파이크 정의(0절)로 NO1의 후보 위치를 찾는다. 좁은 창만 본다: 줌 1.00은 x = 8140\~8390, NO1은 5732\~5982와 8140\~8390. 열마다 엣지 y를 그 창에서 한 번 구한 대략 위치 ± 20px 안에서 찾는다(곡선·단차 구간의 오추적 방지).
4. "양성 대조 재현" = 줌 1.00 시편 5개 중 4개 이상에서 8265 ± 3에 스파이크.

**판정(고정).**
- 양성 대조에서 8265 ± 3에 스파이크가 재현되지 않으면 이 단계는 중단하고 보고한다(방법 문제).
- NO1 스파이크가 **5857 ± 3에만** 있다 → 센서·렌즈·장면 쪽(출력 좌표 고정 아님). JPEG/ISP 출력 단계 설명은 약해진다.
- **8265 ± 3에만** 있다 → 출력 좌표에 붙은 원인(JPEG/ISP 후처리 쪽).
- 둘 다 있거나 둘 다 없다 → 판단 불가. 이유를 적는다(NO1 엣지가 그 열에서 보이는지, 대비가 충분한지).

산출물: `results/E12A_no1_frame.csv`(열 x별 편차 중앙값, 줌 1.00과 1.41), `results/E12A_summary.csv`(후보 위치·깊이·판정), `figures/E12A_no1_frame.png`.

## 2-2. E12-A2 순위 검정으로 다시 보기 (E12-A가 "방법 문제, 중단"이라 새 단계로 재실행)

**왜 새 단계인가.** E12-A의 `strict` 판정은 양성 대조 3/5로 중단이었다(부록). 원인은 두 가지다. ① "창 전체에서 가장 깊은 한 곳"만 보므로 목표 밖에 더 깊은 홈이 있으면 목표의 유효한 홈도 미검출이 된다. ② −0.5px·2열 이상이라는 고정 임계값이 약한 스파이크(NO7, 14µm)를 가른다. 둘 다 규칙의 구조 문제이므로 규칙을 바꿔 새 단계로 다시 한다. **이 규칙은 E12-A 결과를 본 뒤 설계했다(사전 등록이 아니라 사후 설계).** 다만 E12-A2를 실행하기 전에 고정하고 커밋한다. 결과 의존적 조정을 막기 위해 아래를 실행 후 바꾸지 않는다.

**규칙(고정).**
1. 프로파일 `dev(x)`는 E12-A와 같다(열별 엣지 y의 장 방향 중앙값에서 ±6px 롤링 중앙값을 뺌).
2. 통계량 `s(x)` = `dev`의 3열 이동평균.
3. 목표 위치 `xc`(8265 또는 5857)에서 `t = min s(x), |x − xc| ≤ 3`.
4. 오프타겟 집합 = 같은 창에서 `|x − xc| > 8`이고 창 양끝 10열이 아닌 열. 순위 p = (1 + #{오프타겟 s ≤ t}) / (1 + 오프타겟 수).
5. **스파이크 있음 ⇔ p ≤ 0.05 이고 t < 0.** 인접 열은 상관이 있어 실효 독립 수가 줄어든다(보수적이지 않음). 이 한계를 결과에 적는다.
6. 양성 대조 = 줌 1.00 시편 5개(NO3·NO5·NO7·NO9·NO10)의 **본시험 사진 전체**(장수 많을수록 중앙값이 안정됨), 창 x = 8140\~8390. 5개 중 4개 이상에서 "있음"이면 재현. 아니면 "방법 문제, 중단".
7. NO1(본시험 10장 전체)은 5857 창과 8265 창 각각에 같은 검정. 판정 문구는 2절 그대로: 5857에만 있음 → 센서·렌즈·장면 쪽, 8265에만 있음 → 출력 좌표 쪽, 그 외 → 판단 불가. **"없음"은 "p > 0.05"일 뿐 부재의 증거가 아니다**(양성 대조에서 확인된 검출력 범위 안에서만 해석).

산출물: `results/E12A2_summary.csv`, `E12A2_profiles.csv`, `E12A2_verdict.csv`. 코드 `code/e12a2_rank_test.py`(공용 `e12_edges.py`, E12-A와 같은 엣지 추적).

## 2-3. E12-A3 위치 이동 검정 + 보정 + 검출력 (E12-A2 Codex 2차 리뷰 반영)

**왜 새 단계인가.** A2의 p는 목표에서는 "±3열 안의 7열 최솟값"을, 비교 분포에서는 "개별 열 값"을 썼다(통계량 불일치). 같은 7열 최솟값끼리 비교하면 NO1 5857의 p가 0.0485에서 **0.131**로 바뀐다(저장된 프로파일로 재현 확인, 양성 대조는 5/5 유지). 또 NO1 5857 창은 58열이 NaN이고 목표 이하인 오프타겟 7열이 모두 오른쪽에 몰려 비교 분포가 균질하지 않다(좌 0/116, 우 7/57). 규칙의 구조 문제이므로 A2는 탐색 결과로 보존하고 새 단계로 다시 한다. **이 규칙도 A2 결과를 본 뒤 설계했다(사후 설계).** 실행 전에 고정하고 커밋한다.

**규칙(고정).**
1. 엣지 추적: 창 중앙 3열에서 대략 위치를 잡고 **좌우로 직전 열의 y ± 15px를 따라간다**(`window_edges_track`). 못 찾는 열은 NaN이며 y는 직전 값을 유지.
2. 유효 구간: 모든 사진에서 엣지가 유효한 열만 쓴다. 필터 지지구간(13열 롤링 중앙값 + 3열 평균 = 15열)이 전부 유효하지 않으면 그 위치의 s는 NaN.
3. 통계량: `s(x)` = 장 방향 중앙값 프로파일의 롤링 13열 중앙값 제거 후 3열 평균. **`T(c)` = c ± 3의 7열에서 `s`의 최솟값**(목표와 비교 분포가 같은 통계량).
4. 위치 이동 검정: 목표 `xc`의 `T(xc)`를, 같은 창의 모든 위치 `c'`(|c' − xc| > 10, 유효한 `T`)의 `T(c')`와 순위 비교. p = (1 + #{T(c') ≤ T(xc)}) / (1 + n). **있음 ⇔ n ≥ 50, p ≤ 0.05, T(xc) < 0.** 인접 위치는 상관이 있다. 열별 무작위 섞기는 쓰지 않는다. 좌우 분포(왼쪽·오른쪽 오프타겟 수와 T ≤ 목표 개수)를 함께 낸다.
5. **보정(오검출률):** 양성 대조 5개 창, NO1 5857·8265 창 모두에서, 진짜 목표에서 12열보다 먼 가짜 목표 위치(5열 간격)마다 같은 검정(비교 분포도 진짜 목표 ±12 제외)을 해 "있음"이 나오는 비율을 합쳐 낸다. **오검출률 > 0.10이면 검정이 후하게 나오는 것이므로 판정은 "판단 불가(검정 조건 미충족)".**
6. **검출력:** NO1 두 창에서, 모든 사진의 엣지 프로파일에 `[−a/2, −a, −a/2]`(열 3개) 스파이크를 가짜 위치(10열 간격, 진짜 목표 ±12 제외)에 주입하고 전체 전처리 후 같은 검정을 한다. a = 0.5, 1.0, 1.5, 2.0px(양성 대조의 목표 통계량 −0.54\~−1.37px는 a ≈ 0.8\~2.0px에 해당). 검출률을 a별로 낸다. **한 창의 "없음"은 그 창에서 a = 1.0의 검출률 ≥ 0.8일 때만 "미검출"로 해석한다.** 아니면 "검출력 부족".
7. **판정(고정, "기각"·"아님" 표현은 쓰지 않는다):** 사전 조건 = 양성 대조 ≥ 4/5(8265 ± 3에서 "있음"), 보정 오검출률 ≤ 0.10, NO1 두 창의 n ≥ 50. 하나라도 어긋나면 "판단 불가(검정 조건 미충족)". 충족하면
   - 5857 있음, 8265 없음(검출력 충분) → "5857 후보 검출·8265 미검출 — 센서·렌즈·장면 쪽 후보, 원인 판단 보류"
   - 8265 있음, 5857 없음(검출력 충분) → "8265 후보 검출·5857 미검출 — 출력 좌표 쪽 후보, 원인 판단 보류"
   - 그 외 → "판단 불가"

## 3. E12-B 평평한 밝은 영역 열 프로파일 (규칙 개정 2026-10-27, 실행 전)

**개정 이유.** 처음 규칙은 고정 임계값(5·MAD)을 보정 없이 쓰고, 검출력을 재지 않은 채 "없음"을 "엣지 근처에서만 생김"으로 해석하며, 창(8260\~8272)과 위치(8265 ± 3)가 어긋났다. E12-A\~A3에서 겪은 같은 문제이므로 A3 방식(위치 이동 검정 + 보정 + 주입 검출력)으로 바꾼다. **이 개정은 B의 결과를 보기 전에 했다.**

**아이디어.** 엣지와 무관한 영역에서도 x = 8265 열이 어긋나면 열 전체의 결함(센서 열, 렌즈 먼지, 역광판 얼룩, ISP 열 보정)이다. 평평한 곳에서는 멀쩡하고 엣지 근처에서만 튀면 샤프닝·압축·엣지 처리 쪽이다.

**규칙(고정).**
1. 입력: 본시험 110장(NO2\~NO12). 각 장에서 윗엣지 위쪽 밝은 띠(y ∈ [center − 300, center − 120], 저장된 `top_center`)의 **열별 평균 밝기** `m_i(x)`, x = 5900\~11100(분석 위치는 6000\~11000, 나머지는 필터 여유).
2. 유효 열: 어느 한 장이라도 띠 평균이 ≥ 250(포화)이거나 < 150(엣지·그림자 침범)이면 그 열은 무효. 유효 열이 분석 구간의 90% 미만이면 판단 불가.
3. 전처리: 장마다 롤링 15열 중앙값을 빼고(`m_i`가 무효인 곳 포함 15열 지지구간은 NaN), 장 방향 중앙값 `P(x)`(단위: gray level). `s(x)` = `P`의 3열 평균. 양방향(밝아짐·어두워짐)을 모두 본다: **`T(c) = −max |s(x)|, |x − c| ≤ 3`**(작을수록 극단).
4. 위치 이동 검정(A3와 같은 규칙): `xc` = 8265. p = (1 + #{T(c') ≤ T(xc)}) / (1 + n), 비교 위치 c'는 |c' − xc| > 10인 모든 유효 위치(분석 구간). **있음 ⇔ n ≥ 500, p ≤ 0.05.** 부호(밝아짐/어두워짐)와 gray level 크기를 함께 낸다.
5. **가짜 위치 검출 비율(점검):** 분석 구간에서 진짜 목표 ±12열 밖의 가짜 목표 위치(5열 간격)마다 같은 검정(비교 분포도 진짜 목표 ±12 제외)을 해 "있음" 비율을 낸다. **> 0.10이면 판단 불가(검정 조건 미충족).** 이 비율은 같은 T 분포 안에서 순위를 다시 세는 것이라 명목 유의수준 부근이 되기 쉽고, 위치별 배경의 균질성을 검증하는 독립 대조가 아니다. 순위·상관 구조가 심하게 어긋났는지 보는 점검일 뿐이며 "오검출률이 보정됐다"거나 원인 판정의 유효성 근거로 쓰지 않는다. 좌우 비교 분포의 T ≤ 목표 개수를 함께 낸다(불균질 서술). (E12-A3의 "보정 오검출률 0.077"도 같은 의미로 읽는다.)
6. 검출력: 모든 장의 `m_i`에 열 결함을 가짜 위치(50열 간격, 진짜 목표 ±12 제외)에 주입하고(롤링 중앙값 제거 이전, 전체 전처리 후) 같은 검정을 한다. **모양 3가지:** `w1` = [−1]g, `w3` = [−0.5, −1, −0.5]g, `w5` = [−0.5, −1, −1, −1, −0.5]g. g = 0.5, 1, 2, 4 gray level(밝은 띠는 약 200이므로 0.25\~2%). 음수만 주입한다(T가 |s|라 양수는 대칭). **"없음"은 세 모양 모두에서 g = 1의 검출률 ≥ 0.8일 때만 "미검출"로 해석한다**(g = 1은 임의 기준이며 보고서에 그 사실을 적는다). 아니면 "검출력 부족"과 함께 검출률 0.8을 넘는 최소 g를 모양별로 보고한다. **검출력은 이 모양들에 대한 것이다.** 장 방향 중앙값과 15열 중앙값 제거 때문에 폭이 약 7열을 넘는 결함과 특정 시편에만 있는 구조는 제거되거나 사라지므로 검출 대상이 아니다(시편별 결과는 서술용).
6-1. **입력 완전성:** 계산 전에 메타의 본시험 NO2\~NO12가 110장(시편당 10장)이고 모두 캐시에 있는지 검사하고, 아니면 중단한다(다른 표본으로 판정하지 않는다).
7. 시편별(NO2\~NO12, 장 수 10\~15) 같은 검정의 "있음" 여부를 서술로 낸다(판정에 쓰지 않음).
8. **판정(고정).** 사전 조건(보정 오검출률 ≤ 0.10, n ≥ 500, 유효 열 ≥ 90%)을 만족해야 한다. 만족하면
   - 있음 → "평평한 영역에서도 8265 열에 이상 — 열 전체에 걸친 이상(센서·렌즈·장면·ISP 열 처리 모두 해당) 후보, 원인 판단 보류". 장면의 국소 무늬도 이 "있음"에 포함된다(B는 장면과 센서를 가르지 못한다).
   - 없음 + 세 모양 모두 g = 1 검출력 ≥ 0.8 → "모든 장에 공통인 폭 1\~5열·g = 1 이상의 열 결함 미검출 — 열 전체 결함 가설에 불리, 엣지 영역에 국한된 원인은 배제하지 못함, 원인 판단 보류". **밝은 띠의 미검출만으로 원인을 샤프닝·압축 쪽으로 좁히지 않는다.**
   - 그 외 → "판단 불가"
   사전 조건 불충족 → "판단 불가(검정 조건 미충족)". "기각"·"아님" 표현은 쓰지 않는다.

산출물: `results/E12B_summary.csv`, `E12B_pseudo_hits.csv`, `E12B_power.csv`, `E12B_by_specimen.csv`, `E12B_verdict.csv`, `figures/E12B_flat_column.png`. 코드 `code/e12b_flat_column.py`(A3의 `shift_p`를 재사용).
