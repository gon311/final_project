## 배경 (2026-10-30 멘토링)

현장 작업자는 베어링부(폭 10.2mm)의 **중앙**을 마이크로미터로 몇 차례 재서 대표값을 기록한다. 이미지 쪽은 구간 전체의 여러 개소를 모아 대표값을 만들기 때문에 실측치와 어긋날 수 있다. 멘토 제안: 31개소 중 중앙 10개소, 다시 중앙 5개소만 써서 실측치와 비교한다.

확인된 사실 (사용자, 2026-10-30):
- 실측치는 마이크로미터로 쟀고, "중앙부분"을 쟀다고만 들었다. 측정 위치·횟수·각도의 수치 기록은 없다.
- `PREREG_E11.md`의 "중앙 기준 좌 2mm·우 3mm"는 **거칠기** 측정 구간이며 치수 측정 구간이 아니다.

현재 파이프라인과의 차이 (코드로 확인):
- "31개소"는 1차 실험(팀 YOLO 파이프라인, 측정선 31개의 **중앙값**)의 설정이다. 2·3차는 2px 간격 열을 쓰며, 10/21은 이미지당 110~111열이다.
- 10/21 `measure_bearing`은 베어링 구간(약 9.7mm) 양끝을 20%씩 잘라 **중앙 약 5.8mm**만 쓰고, 열 평균이 아니라 상·하단 엣지 강건 직선적합의 중앙 거리(`d_line`)를 대표값으로 쓴다. 직선은 중앙에서 평가하므로 구간을 대칭으로 좁혀도 값이 거의 같아야 한다. 달라진다면 원인은 직경의 x 방향 휘어짐이나 구간 끝 아티팩트(E11-A, x≈8265) 때문이다.
- 외측 마이크로미터는 평면 측정면(일반 규격 지름 6.35mm, 실제 기종은 미확인)으로 축을 끼우므로, 그 폭 안의 **최대 직경**에 가까운 값을 읽는다. 그래서 "좁힌 구간의 평균"과 함께 "구간 안 최댓값 계열"도 후보에 넣는다.

## 2. 이미지 한 장의 후보 대표값 (px)

공통 정의:
- 기울기 θ: 전체 창의 상·하단 강건 직선적합(`measure.py`의 `robust_fit`, 4·1.4826·MAD) 기울기 평균. R0와 같다.
- 열 직경: d(x) = (y_bot(x) − y_top(x)) · cos θ.
- 창 중앙: xm = (그 이미지의 최소 x + 최대 x) / 2.
- 길이 환산: V1 = 0.026092 mm/px (`repeatability_ratio.json`).
- 31개소 환산: 10.2mm에 31개를 고르게 놓으면 간격은 0.34mm다. 중앙 10개는 9간격(3.06mm), 중앙 5개는 4간격(1.36mm)을 차지한다. 10개는 정중앙 기준으로 대칭이 안 되므로 대칭 창 ±1.53mm로 근사한다.

| 기호 | 정의 | 의미 |
|---|---|---|
| **R0** | `d_line` (현재 방식) | 기준 |
| **R1** | 전체 창 d(x)의 평균 | "전 개소 평균" |
| **R2** | \|x − xm\| ≤ 1.53mm(±58.6px) 열 d(x)의 평균 | 멘토 안: 중앙 10개소 상당 |
| **R3** | \|x − xm\| ≤ 0.68mm(±26.1px) 열 d(x)의 평균 | 멘토 안: 중앙 5개소 상당 |
| **R4** | 전체 창 d(x)의 90% 분위수 | 마이크로미터(접촉 폭 안 최대) 근사 |
| R5 (보조) | 전체 창 d(x)의 최댓값 | 보고만 |
| R1m·R2m·R3m (보조) | R1~R3에서 평균 대신 중앙값 | 보고만 |

- 멘토 설명이 "평균"이라 R1~R3의 주 집계는 평균으로 둔다.
- R4는 사용 가능한 창이 약 5.8mm라서 6.35mm 접촉 폭보다 조금 좁다.

그 시편 이미지들의 R 값 **중앙값** (E6 규칙과 같음).

## 4. 보정과 평가

- 분할: 정상 9시편 LOSO. 원본 `experiments/2nd/E6_calibration/calibration.py`의 함수를 수정 없이 import해서 쓴다.
- **방식 3 (V1 스케일 고정, mm = 0.026092·px + c, 주):** 기울기가 물리값으로 고정돼 있어서, 대표값을 바꾼 효과가 기울기 재적합에 흡수되지 않고 그대로 드러난다.
- 방식 4 (핀비율 정규화 선형, 보조): ratio = R / `pin_cross50_px`. E6에서 가장 좋았던 방식이지만, 실측 폭이 21µm인 8점으로 기울기를 맞추므로 불안정하다(E6 방식 2의 기울기 0.0092는 물리값 0.0261과 다르다).
- 지표: 시편별 |오차|(µm), MAE, MAX.

## 5. 판정 규칙 (주 비교)

- 대상: 방식 3, all, {R1, R2, R3, R4} 각각을 R0와 비교 (4개 비교).
- 시편별 Δ_i = |err_R,i| − |err_R0,i| (i = 9시편). 평균 Δ에 대한 정확 부호뒤집기 검정(2⁹ = 512가지), 단측(개선 방향).
- Holm 보정(4개). **"개선"**은 Holm 보정 p < 0.05 **이면서** MAE 감소가 1µm 이상(마이크로미터 분해능 0.001mm)일 때만이다.
- n = 9라 검정력이 낮다. 유의하지 않다고 해서 효과가 없다는 뜻은 아니며, 결론에는 "이 자료로는 구분할 수 없다"고 쓴다.
- 멘토가 물은 단계 비교(R3 vs R2)와 방식 4·burst·보조 R은 기술 통계로만 보고하고 판정에는 쓰지 않는다.

## 6. 1단계: 열별 직경 프로파일 (기술, 규칙을 바꾸지 않음)

- 이미지마다 d(x) − median d(x)를 x − xm(mm)에 대해 구하고, 시편별로 이미지 중앙값 곡선을 그린다(그림 1장, 11시편).
- 이미지마다 대비 c = mean(d, |x−xm| ≤ 0.68mm) − mean(d, 전체 창)을 µm로 구해 시편별 중앙값과 IQR를 보고한다.
- 끝열 효과: 양끝 3열 평균 − 나머지 평균(µm), 좌우를 따로 보고한다.
- 미리 정한 해석: 시편별 |c|의 중앙값이 장착 내 σ(2.9µm)보다 작으면, R2·R3가 R0보다 잡음 이상으로 나아질 근거가 약하다고 본다.
