# 파이널 프로젝트 — 샤프트 외경 실험 2nd 정리 (E1\~E6)

Oct 14, 2026 · @이다겸

## 한눈에 보기

10월 8일 촬영 데이터로 진행한 2차 실험(E1–E6)의 결론은 이렇다. **이 데이터만으로는 사진에서 공차 ±0.01mm를 믿을 만하게 가려내는 보정식을 만들 수 없다.** 측정 코드가 부정확해서가 아니라, 사진마다 달라지는 조건(카메라 위치, 초점, 시편이 놓인 자리)이 우리가 찾으려는 신호보다 훨씬 크기 때문이다.

측정은 이렇게 이뤄진다. 백라이트로 찍은 샤프트 실루엣에서 위·아래 경계선을 찾고, 둘 사이 거리를 픽셀(px)로 잰 뒤 mm로 바꾼다. 이 셋업에서 1px은 약 0.037mm다. 공차 ±0.01mm는 **0.27px**, 즉 픽셀 한 칸의 약 1/4이다.

| 실험 | 무엇을 했나 | 한 줄 결과 |
| --- | --- | --- |
| E1 측정 모듈 정리 | 기존 분석 코드를 저장소로 옮기고 같은 숫자가 나오는지 확인 | 130장 모두 소수점 11자리까지 일치 |
| E5 핀게이지 | 사진 속 Ø10 기준 핀으로 배율·카메라 이동을 보정할 수 있는지 확인 | 보정용으로는 불가, 촬영 상태를 감시하는 용도로는 유용 |
| E3 하단 경계 | 샤프트 아랫면 경계가 왜 계단처럼 여러 겹인지 분석 | 베어링부 아랫면만 진짜 여러 겹, 윗면과 핀은 한 겹 |
| E4 경계 정의 | 경계를 어디로 볼지 정하는 방법 6가지를 비교 | cross50과 moment가 가장 안정적, 어느 쪽도 실측과 유의한 관계 없음 |
| E6 보정식 | 픽셀을 mm로 바꾸는 방식을 비교 | 평균만 답하는 방식을 확실히 이기는 방법 없음 |
| E2 증강 | 학습 데이터를 늘릴 때 쓰는 변형이 정답을 바꾸는지 확인 | 안전한 변형은 일부뿐 |

모델을 학습시키는 단계(E7–E9)는 아직 진행하지 않았다. 이번 결과가 그 단계의 전제를 흔들기 때문이며, 이유는 3절에 적었다.

## 1. 이 실험의 결론

**지금 데이터로는 "사진 → mm" 보정식을 확정할 수 없다. 원인은 측정 방법이 아니라 사진 조건의 변동이다.** 같은 시편을 같은 자리에 두고 연속으로 찍으면 결과가 잘 맞지만(반복 오차 약 4µm), 시편을 바꾸거나 다시 올려 찍으면 공차보다 큰 폭으로 달라진다.

| 이 데이터로 되는 것 | 이 데이터로 안 되는 것 |
| --- | --- |
| 촬영 상태(초점 변화, 카메라 이동) 감시 | 사진 → mm 보정식 확정 |
| 상단 경계의 위치 추정 연습 | 불량(NG) 판별 성능 주장 |
| 안전한 증강과 위험한 증강 구분 | 아랫면 경계의 "정답 위치" 확정 |
| 경계 정의 후보 2개로 좁히기 | 핀게이지로 샤프트 배율 보정 |

### 근거 1. 측정 없이 평균만 답해도 지금의 보정식보다 못하지 않다

정상 시편 10개의 실측 평균(약 20.019mm)을 그대로 답하는 방식을 "평균 찍기"라 부른다. 시편을 하나씩 빼고 나머지로 맞춘 뒤 빠진 시편을 예측하는 방식(LOO)으로 비교했다.

| 방식 | 평균 오차(µm) | 평균 찍기 대비 | 정상품을 불량으로 오판(10개 중) |
| --- | --- | --- | --- |
| 평균 찍기 (측정 없음) | 5.78 | 기준 | 0 |
| grad\_peak + 전체 선형회귀 | 5.68 | −0.10 | 0 |
| cross50 + 핀 비율 보정 | 3.95 | −1.82 | 1 |
| cross50 + 전체 선형회귀 | 7.22 | +1.44 | 0 |
| 희연님 방식(NO4–6 3점 선형, cross50) | 14.18 | +8.40 | 5 |
| 물리 스케일 0.0367mm/px 고정 | 26.88 | +21.10 | 7 |

- 평균 찍기가 5.78µm로 잘 나오는 이유는 정상 시편이 모두 20.010–20.030mm 안에 모여 있기 때문이다. 이 숫자는 판별력의 증거가 아니라 "평가 데이터가 쉽다"는 뜻이다.
- 가장 근접한 방식은 grad\_peak + 전체 선형회귀다. 6개 조합 중 5개에서 평균 찍기보다 근소하게 낮았지만(최대 약 1µm), 같은 장착에서 10장을 반복해 찍을 때의 흔들림(3.4–5.0µm)보다 작다. 방법이 좋은 것인지 촬영 잡음인지 구분되지 않는다.
- 핀 비율 보정은 시편 하나씩 빼는 평가(분할 A)에서는 이기지만, 희연님 방식대로 NO4–6으로 맞추고 NO7–10을 예측하는 평가(분할 B)에서는 진다(−1.82 → +4.23µm). 방향이 뒤집히므로 "이긴다"고 쓰지 않는다.
- 물리 스케일 고정은 모든 조합에서 가장 나빴다(11–64µm).

### 근거 2. 희연님 방식의 "40/40 OK"는 판별력 증거가 아니다

희연님 엔진 경로를 그대로 재현했다. 기울기 2.586µm/px, 불량 NG1·NG2 20장 전부 OK 판정이다(민욱님 재현값 약 2.57과 일치). 즉 이 식은 불량을 잡지 못한다. 기울기가 물리 스케일의 1/14에 불과해서 어떤 사진이 들어와도 20.017–20.020mm 근처만 답하기 때문이다. NO4 한 시편이 아랫면의 다른 겹을 잡아 +5.7px 튄 값이 3점 직선을 끌어당긴 결과로 본다.

### 근거 3. 사진 사이의 변동이 찾으려는 신호보다 훨씬 크다

- 같은 장착에서 연속 10장: 표준편차 0.11px(약 4µm). 공차보다 작아서 양호하다.
- 같은 시편 NO1을 처음과 마지막에 두 번 올려 찍은 차이: 0.62px(약 23µm). 공차 반폭(10µm)의 2배 이상이다.
- 시편 사이 범위: 3.43px(약 126µm). 실측 차이가 만들어야 할 범위는 1.0px(약 37µm)뿐이다.
- 시편을 바꾼 거의 모든 시점에서 고정물이 1px 넘게 움직였다(최대 약 40px). 13개 촬영 묶음 중 12개가 "재촬영 권고"에 걸렸다.
- 9번→10번 시편, 10번→11번 시편 전환에서 샤프트 높이가 −17px, +19px 뛰었는데 카메라 이동으로 설명되지 않는다. 시편이 놓인 높이 차이 후보이며, 확정은 재장착 반복 촬영이 필요하다.

### 근거 4. 하단(아래쪽) 경계는 "정답 위치"가 하나가 아니다

사진 위쪽 경계(상단)는 가림막으로 가렸고, 아래쪽 경계(하단)는 가리지 않았다. 경계선 후보가 여러 개 경쟁하는 정도를 "가장 약한 후보 ÷ 가장 강한 후보"로 재면, 베어링부 하단만 뚜렷이 다르다.

| 구간 | 가장 약한 ÷ 가장 강한 | 해석 |
| --- | --- | --- |
| 핀 상단 | 0.012 | 한 겹 |
| 베어링부 상단 | 0.024 | 한 겹 |
| 핀 하단 | 0.053 | 한 겹 |
| 우측 직선부 하단 | 0.113 | 약한 여러 겹 |
| 베어링부 하단 | 0.189 | 뚜렷한 여러 겹 |

- 하단의 겹 사이 간격은 5–10px(약 0.2–0.4mm)로, 공차 0.01mm보다 훨씬 크다. 어느 겹을 경계로 잡느냐에 따라 지름이 크게 달라진다.
- 하단 기준 문턱을 10%에서 90%로 옮기면 지름이 약 14px(약 0.5mm) 커진다. 그런데 어느 문턱도 실측과 유의한 관계가 없다(상관 −0.42 – +0.45, 모두 p > 0.2). 민욱님의 81조합 결과(정답을 보고 골라도 최선 p = 0.19)와 같은 결론이다.
- 핀에는 여러 겹이 없다. 가림 여부와 여러 겹이 함께 나타나므로 "가리지 않은 백라이트가 샤프트 아래를 스친다"는 민욱님 추정과 방향이 맞다. 다만 함께 나타난다는 상관일 뿐 원인을 확인한 것은 아니다.

### 근거 5. 경계 정의는 cross50과 moment를 후보로 좁혔다 (현재 촬영 조건 한정)

- **cross50**(밝기가 절반으로 바뀌는 지점)와 **moment**(밝기 변화의 무게중심)가 가장 안정적이다. 같은 장착 10장의 표준편차가 각각 0.12px 안팎이다.
- **grad\_peak**(밝기 변화가 가장 가파른 지점)는 NO4에서 +5.7px 튄다. 희연님 엔진을 다시 돌려도 같은 시편에서 같이 튜다(550.30px와 550.37px).
- **ESF**(경계를 매끄러운 계단 모양으로 맞추기) 2·3단은 적합 실패율이 67%·81%라 기준 라벨로 쓸 수 없다.
- 이 선택을 실측과의 상관으로 하지 않았다. 실제로 ESF 2단이 6개 묶음에서 r = 0.84(p = 0.07)로 좋아 보였지만, 실패한 적합을 빼기 전에는 p = 0.002로 더 "확실해 보였다." 정답을 보고 고르면 속는다는 사례로 남겼다.
- 재장착을 반복해 보지 못했으므로 "확정"이 아니라 "후보"다.

### 근거 6. 핀게이지(Ø10)는 보정용이 아니라 촬영 상태 감시용이다

- 초점이 F1/F2에서 F3로 바뀔 뒤 핀 폭이 약 +0.5% 커졌다. 샤프트는 약 +0.25%만 커졌다. 둘이 같은 비율로 변하지 않아 핀으로 샤프트 배율을 보정하면 오히려 나빠진다.
- 핀과 샤프트를 한 식으로 잇는 모델은 화면 배율을 0.03648mm/px(물리 스케일의 99.4%)로 맞추었지만, 학습에 쓰지 않은 NG1·NG2를 예측하면 틀린다. 실측 19.993·20.002인데 예측은 20.036·20.049로 +42.6µm·+46.9µm 높고, 하한 아래여야 할 값이 상한 위로 나왔다. 배율이 물리 스케일과 비슷하게 나온 것은 핀 하나와 샤프트 평균 두 점으로 맞춘 결과라 검증 근거가 아니다.
- 핀 측정 위치는 "핀 왼쪽 끝에서 60–105px"로 정했다. 카메라가 밀리면 고정 좌표가 핀의 다른 부위를 재기 때문이다. 핀이 움직인 시점은 묶음 1과 2 사이로 판단했다(민욱님과 같고 분류표의 "묶음 1 안"과는 다르다).
- 핀 폭으로 초점 상태(F1/F2와 F3)를 가르고 NO7 안의 초점 흐름(−0.39px)도 잡는다. 다만 F1과 F2는 값이 겹쳤서 구분하지 못한다.

### 근거 7. 안전한 증강은 일부뿐이다

증강은 학습 사진을 늘리려고 흐림·밝기·회전 같은 변형을 가하는 기법이다. 변형을 가했는데 경계선 위치가 0.03px 넘게 움직이면 "정답이 바뀔 것"이라 측정 학습에 쓸 수 없다(게이트 전용: 사진 품질 검사나 위치 찾기 모델에만 사용). 130장 전체와 촬영 묶음별 최악 조건까지 봐서 낸 판정이다.

| 변형 | 상단 | 하단 |
| --- | --- | --- |
| 어둡게 −10, −20 | 허용 | 허용 |
| 대비 ×0.8 (줄임) | 허용 (위치 변화 정확히 0) | 허용 |
| 흐림 σ=0.5 | 허용, 단 일부 촬영에서 기준 초과 | 허용 |
| 흐림 σ=1 | 게이트 전용 | 허용 |
| 흐림 σ=2 | 게이트 전용 | 게이트 전용 |
| 밝게 +10 이상, 대비 ×1.2, 감마 0.8·1.25 | 게이트 전용 | 게이트 전용 |
| 작은 회전 ±0.25°–1.0° | 지름 기준 대체로 허용 (−1.0°만 초과) | 단, 아래 경계가 다른 겹으로 옮겨가는 경우 최대 50–75% |
| 0.25·0.5px 평행이동 | 이동량만큼 정확히 따라감 (기대대로) | 이동량만큼 정확히 따라감 |

- 밝게 만드는 변형이 특히 위험한 이유는 배경이 이미 밝아(약 245/255) 금방 최대치에 맞닿기 때문이다. 밝기를 올리면 경계 형태 자체가 달라진다. 어둡게 하는 쪽은 안전하다.
- 해상도: 2×2 화소 평균 축소(50MP 상당)는 지름이 평균 0.05–0.09px(약 2–3µm) 달라지는 정도로 양호하지만, 촬영 묶음별 최악은 0.14–0.22px다. 4×4(12.5MP 상당)는 0.49px(약 18µm)로 뚜렷이 나쁘다. 다음 촬영이 50MP면 코드를 그대로 쓸 수 있지만 재확인이 필요하다.
- 작은 회전은 지름 때문에 괜찮아 보이지만, 하단 경계가 어느 겹에 걸리는지는 바뀔 수 있어 라벨은 믿기 어렵다.

## 2. 이 실험의 문제의식

**모델을 학습시키기 전에, 이 데이터가 무엇을 가르칠 수 있고 무엇은 못 가르치는지 먼저 확인해야 했다.** 아래 세 사실이 이 실험의 출발점이다.

- 희연님 측정 엔진(YOLO로 위치를 찾고 OpenCV로 경계를 재는 구조)이 새 시편에서 오차를 냈다.
- 10월 8일에 새로 촬영한 데이터는 130장이지만 독립된 촬영 묶음(셋업)은 13개뿐이다. 한 묶음의 10장은 거의 같은 사진이다.
- 멘토 회의(10/10) 조언: 큰 모델보다 도메인 특화 경량 모델(증류), 경계 추출이 정답과 얼마나 맞는지 먼저 검증, 하단의 연한 빛 산란 영역을 잘못 잡았을 가능성, 기준 핀게이지 값이 오차 범위 안인지 확인. (회의록은 자동 요약본이라 원 발언과 표현이 다를 수 있다.)

이 상태로 시편 12개의 지름(mm)을 바로 학습시키면 모델이 지름이 아니라 "그날 촬영 잡음"을 외운다. 확보한 정답이 13개뿐인데 사진 조건은 시편마다 달랐기 때문이다. 그래서 전제를 먼저 재었다.

### 찾으려는 신호와 촬영 잡음의 크기

같은 장착에서 연속으로 찍은 10장은 공차 안에 들어오지만, 시편을 바꾸거나 다시 올려 찍으면 공차 반폭을 넘는다. 시편이 바뀌면 변동(62–126µm)이 찾으려는 신호(37µm)보다 커진다.

### 이 실험이 던진 질문

| 질문 | 쉽게 말하면 | 담당 실험 |
| --- | --- | --- |
| 키가 큰 사람이 사진에서도 크게 찍히는가? | 사진 속 지름(px)이 실측 지름(mm)과 함께 움직이는가, 보정식을 만들 수 있는가 | E6, E4 |
| 아래쪽 경계는 어느 선이 진짜인가? | 경계가 계단처럼 여러 겹인 이유와 어느 겹을 경계로 삼을지 | E3, E4 |
| 촬영 조건이 바뀐 것을 기준물로 보정할 수 있는가? | 사진 속 Ø10 핀게이지를 자로 쓸 수 있는지 | E5 |
| 학습 사진을 늘려도 정답이 안 바뀌는 변형은 무엇인가? | 증강 목록을 가려내기 | E2 |
| 모든 실험이 같은 측정 코드를 쓰는가? | 재현 가능한 공통 코드 | E1 |

### 실험을 이렇게 설계했다

- 평가는 항상 촬영 묶음(셋업) 단위로 한다. 같은 묶음의 사진을 학습과 평가에 나눠 넣지 않는다.
- 불량 시편 NG1·NG2(실측 19.993, 20.002)는 평가에만 쓴다. 하한 아래로 나왔는지, 상한 위로 나왔는지 방향도 본다.
- 오차표의 첫 줄은 항상 "평균 찍기"다. 그것보다 확실히 낫지 않으면 측정이 정보를 담고 있다고 보지 않는다.
- 상관관계를 근거로 쓸 때는 실측값을 무작위로 섞어 다시 계산하는 검정(순열검정) p값을 함께 확인한다.
- 결론은 "13개 묶음, 재장착 반복 없음"이라는 한계 안에서만 말한다.
- 각 실험은 코드 리뷰(Codex)를 거쳐 오류를 고쳤다. 예를 들어 E2는 회전 보정 누락을 고친 뒤 "회전 전부 안 됨"에서 "대체로 허용"으로 결론이 뒤집혔다.

## 3. 이 실험 결과 남는 의문점, 발전 방향

**가장 큰 의문은 "하단 경계의 정답이 어디인가"와 "사진마다 달라지는 값이 촬영 때문인지 시편 때문인지"다.** 둘 다 이 데이터로는 풀 수 없고, 다음 촬영을 어떻게 설계하느냐로 해결해야 한다.

### 남는 의문점

| 의문 | 지금까지 아는 것 | 풀려면 |
| --- | --- | --- |
| 하단의 어느 겹이 실제 외곽인가 | cross50은 가장 센 겹(거의 항상 2단)을 따라가지만 바깥 겹이 아닐 수 있다. 가림 여부와 함께 나타난다. | 지름을 아는 핀게이지를 샤프트 자리에 놓고 촬영 |
| 시편마다 px가 다른 것은 시편 지름 때문인가 촬영 조건 때문인가 | px와 실측의 관계가 없다(r = −0.35, n = 13). 초점·카메라·시편 교체가 동시에 일어나 분리할 수 없다. | 같은 시편 재장착 반복, 같은 시편 세트를 모든 조건에서 반복 |

| 민욱님 결과와 다른 항목들(4절 참고) | 구현 세부(샘플링 창, 블러 커널) 차이일 수 있다. | 두 구현을 같은 사진에 나란히 실행 |

### 발전 방향

**다음 촬영에서 바꿀 것**

- 지름을 아는 핀게이지 세트(Ø19.99, 20.00, 20.01, 20.02, 20.03 등)를 샤프트 자리에 놓고 같은 조건으로 찍는다. 경계 정의와 보정식의 정답을 물리적으로 정해 준다.
- 같은 시편을 다시 장착해 찍는 재장착 반복(시편 3–5개 × 재장착 3회 이상 × 회전각 2–3개 × 각 5–10장)으로 놓임 변동이 얼마인지 직접 잰다.
- 폰을 단단히 고정하고 시편을 바꿀 때마다 고정물(V블록 모서리) 위치를 확인한다.
- 초점·노출·화이트밸런스를 수동으로 고정하고 가능하면 RAW(DNG)로 저장한다. 조건을 바꿀 때는 같은 시편 세트를 모든 조건에서 반복해 시편 효과와 조건 효과를 섞지 않는다.
- 핀을 샤프트 축과 같은 깊이에 두고 카메라에서 핀·샤프트까지의 거리를 재둔다.
- 불량(NG) 시편을 상한·하한 양쪽으로 늘리고, 마이크로미터 측정 위치(축 방향 위치·회전각)를 기록한다.
- 하단을 가린 촬영과 가리지 않은 촬영을 번갈아 찍어 경계가 여러 겹으로 보이는 원인을 확인한다.

**분석에서 이어갈 것**

- 새 데이터가 오면 E6 스크립트(평균 찍기 기준선 포함)의 입력만 바꿔 그대로 다시 돌린다. 이미 일반화해 두었다.
- 셋업 모니터 규칙(핀 px + 고정물 이동으로 "이 묶음은 재촬영 필요" 표시)을 촬영 중 점검 도구로 쓴다.
- 증강은 "허용"으로 판정된 변형만 쓰고, 하단은 따로 판단한다.
- 평가 기준을 공차 대비 %GRR, 불량 검출률·오검출률, 시편 순위 상관으로 바꾼다. 정상품만으로 OK율을 보지 않는다.

**모델 학습 단계(E7–E9)에 대한 제안.** 지금 라벨로 쓸 수 있는 cross50·moment는 "사진에서 가장 센 경계"일 뿐 물리적 외곽이 아니다. 지금 학습시키면 "기준 라벨을 얼마나 잘 따라 하는가"는 알 수 있어도 측정 정확도는 알 수 없다. 따라서 상단 경계부터 파이프라인을 확인하는 정도로 한정하고, 핀게이지 정답이 생기면 라벨을 교체하는 방식을 제안한다.

### 팀에서 정해야 할 것

- [ ] 경계 정의를 cross50으로 통일할지 (희연님 엔진은 gradient 계열)
- [ ] 다음 촬영 프로토콜(핀게이지 세트, 재장착 반복 횟수)과 일정
- [ ] E7–E9(경량 모델 학습)를 다음 촬영 이후로 미룰지
- [ ] 평가 기준(%GRR, 불량 검출률)과 평균 찍기 기준선 사용 합의

## 4. 희연님·민욱님 작업과의 공통점과 차이점

**세 작업은 방법이 달라도 같은 결론에 도착했다. 하단 경계는 불안정하고, 평균 찍기를 확실히 이기는 방식이 없고, 촬영 조건의 변동이 신호를 덮는다.** 차이는 주로 "어디까지 확인했는가"와 몇몇 수치의 불일치에 있다. 두 분 작업의 내용은 팀원C가 이해한 내용을 토대로 적은것이므로, 틀린 부분이 있다면 두 분이 직접 확인해 주길 바란다.

### 희연님 작업과 특히 다른 점

- 경계 정의: 희연님 엔진은 gradient가 가장 센 지점을 연속성 규칙으로 고르는 방식이고, 이번 실험은 밝기 50% 지점(cross50)을 1순위로 봤다. gradient 방식은 NO4처럼 다른 겹을 잡으면 크게 튄다.
- 보정: 희연님은 NO4–6으로 3점 보정 뒤 NO7–10을 검증했다. 이번엔 시편 하나씩 빼는 평가와 평균 찍기 기준선을 함께 써서 "40/40 OK"가 판별력 증거가 아님을 확인했다. 희연님도 NO1–3 보정이 실패한 뒤 NO4–6으로 역할을 바꿨다.

### 서로 다른 것을 했다

- 이번 실험에서만 한 것: 증강 영향(E2), ESF·moment까지 포함한 경계 정의 비교(E4), 130장 전수와 묶음 단위 평가, 순열검정, NG 판정 방향 확인, 핀 측정 위치 결정(E5), 핀 + 샤프트 2-물체 모델의 NG 예측 시험.
- 민욱님만 한 것: 멘토 코드(MKD) 이식, 경량 YOLO 시험, 카메라 이동 원자료 측정, 오차 패턴 후보 7개, 문턱 81조합.
- 희연님만 한 것: 측정 엔진 구현(YOLO ROI, 연속성 선택, 반사띠 마스크)과 40장 검증.

| 서브픽셀 | 픽셀 한 칸보다 더 잘게 위치를 추정하는 것. |
| 셋업(묶음) | 시편을 한 번 장착해 연속으로 찍은 10장. 독립 셋업은 13개. |
| F1/F2/F3 | 촬영 중 초점이 바뀐 구간 표시. 의도한 설정값이 아니다. |
| 핀게이지(Ø10) | 지름 10.000mm인 기준 막대. 사진 속 샤프트 오른쪽 끝 옆에 있다. |
| NG1·NG2 | 일부러 공차 밖으로 만든 불량 시편(실측 19.993, 20.002). 둘 다 하한 아래. |
| 평균 찍기 | 사진을 보지 않고 정상 시편의 평균을 그대로 답하는 방식. 최소한 이겨야 하는 기준선이다. |
| LOO | 시편 하나를 빼고 나머지로 만든 식으로 그 시편을 예측해 보는 평가. 분할 A가 이 방식이고, 분할 B는 희연님 방식(NO4–6으로 맞추고 NO7–10을 예측). |
| cross50 | 배경에서 샤프트로 밝기가 절반 바뀌는 지점을 경계로 보는 정의. |
| grad\_peak | 밝기 변화가 가장 가파른 지점을 경계로 보는 정의(희연님 엔진 계열). |
| moment | 밝기 변화 전체의 무게중심을 경계로 보는 정의. |
| ESF | 경계를 매끄러운 계단 모양 곡선으로 맞춰 위치를 구하는 정의. 1단·2단·3단 모델. |
| 순열검정, p값 | 실측값을 무작위로 섞어 같은 계산을 반복해, 우연히 이만큼 나올 확률을 본다. p가 크면 우연일 수 있다. |
| 증강, 게이트 | 증강은 학습 사진을 늘리려고 흐림·밝기·회전 등을 가하는 것. 게이트는 측정 전에 "이 사진으로 재도 되는가"를 검사하는 단계. |
| teacher/student(증류) | 정밀하지만 무거운 방법(teacher)의 결과를 작은 모델(student)이 따라 하도록 학습시키는 방식. |
| GT | 실제 값을 알고 있는 정답. 이번에는 공칭 핀게이지 세트로 만들자는 제안. |
| 재장착 반복(GR&R) | 같은 시편을 여러 번 다시 끼워 찍어, 측정 변동 중 장착 때문인 몫을 재는 시험. |
| 상관계수 r | −1에서 +1 사이 값. 두 값이 함께 움직이는 정도. 0에 가까우면 관계가 약하다. |
