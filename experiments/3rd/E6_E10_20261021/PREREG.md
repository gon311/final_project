# 10/21 3차 촬영 — E6·E10 실행 전 고정 규칙 (사전 등록)

- 작성: 2026-10-22, 베어링 전체 스캔(NO3~NO12)과 판별 결과를 보기 **전**.
- 이 문서의 규칙은 결과를 본 뒤 바꾸지 않는다. 바꿔야 하면 "사후 변경"으로 따로 적는다.

## 0. 결과 전에 이미 본 것 (공개)
- 190장 전체의 Ø16 핀 px(셋업 점검용, 샤프트 아님): 본시험 중 −0.21% 드리프트, NO1 +0.36%, 암막없음 +3%.
- 구간 식별용으로 NO2·NO7·NO12 각 1장의 샤프트 구간 높이(대략값)와 NO2·NO12 엣지 프로파일 모양.
  NO12(NG2)의 베어링 대략값을 한 번 봤다(NO2와 0.3px 이내). 판별 규칙 선택에 쓰지 않았다.
- NO2 본시험 10장의 베어링·핀 측정값(상수 결정용). NO1 1장의 측정값(프레임 보정 확인용).

## 1. 데이터 범위
- 주 분석: 1_본시험_암막 NO2~NO12(110장) + 2_재장착_암막 NO7~NO12(30장, 장착당 1장).
- NO1: CAL에서 제외(디지털줌·초점 전·셔터/ISO 다름). E6에서 민감도 확인용으로만 예측값을 따로 적는다.
- 3_암막없음: 제외(엣지가 실루엣이 아님). 기록지 사진 2장 제외.

## 2. 레이블·판정
- 실측mm: 00_3차촬영_사진목록 엑셀. 공차: 20.010 ≤ OK ≤ 20.030(경계 포함).
- NO9(20.009): **경계군**. LOSO 학습·MAE에는 포함, OK/NG 판정 집계(정상 오판정 수)에서는 제외.
- NG: NO11(19.968, 하한 아래), NO12(20.044, 상한 위). 학습에 넣지 않고 정상 9시편 전체로 맞춘 모델로 평가만 한다.
- NG 방향 판정 3단계: ① NG로 판정 + 방향 맞음, ② 방향만 맞음(OK 판정), ③ 방향 틀림. 방향 = 공칭 20.020에서 벗어난 부호.

## 4. 스케일
- 기준물: Ø16 핀게이지(팀 확인).
- V1 물리 스케일: `16 / median(pin_cross50_px, 본시험 NO2~NO12)` mm/px. 샤프트 사진은 쓰지 않는다.
- V2 핀 비율: `16 × D / pin_px + c`.

## 5. 집계 단위
- 시편 대표값: 그 시편의 **모든 이미지(본시험+재장착) 중앙값**(E6·E10 원 코드 규칙 그대로). 보조: 본시험만.
- 1장 판정(보조 지표, E6): 학습 시편으로 맞춘 식을 held-out 시편의 각 이미지에 단독 적용 → 정상 이미지 오판정률, NG 이미지 검출률.

## 6. 반복성 기준선 (판별 결과 전에 계산)
- 동일 장착: 정상 시편(NO2~NO10) 본시험 10장 σ의 중앙값(cross50, µm 환산은 V1 스케일).
- 재장착: NO7~NO12 각 6회 장착값(본시험=10장 중앙값, 재장착=1장)의 시편 내 σ — 원시 px와 핀 비율 보정 후 둘 다.
- E10 해석 규칙 1의 기준값 = 동일 장착 기준선(10/08의 3.4µm 대체).

## 7. 비율 실험 (주 보정 방법 결정)
- 자료: NO7~NO12 × 6장착(36점). 시편별 평균을 뺀 Δbearing_px를 Δpin_px에 회귀(절편 0, 합동 OLS, t 기반 95% CI). 보조: 시편 단위 부트스트랩 2000회.
- 기대 기울기 = 베어링 px / 핀 px(NO2 기준 754.5/614.0 ≈ 1.23). 절반 따라감 = 0.61.
- 판정: CI가 1.23 포함 & 0.61 제외 → **V2(핀 비율) 주 방법**. CI가 1.23 제외 → **V1 주 방법**. 둘 다 포함 → **판정 불가 → V1 주 방법**, 드리프트(본시험 중 −0.21%)를 한계로 명시하고 NO12 판정은 "드리프트 영향 범위 안"으로 표시.
- 마이크로미터 값은 쓰지 않는다.

## 8. E6
- 정의: cross50(주), grad_peak, moment. 방식: 0 평균찍기, 2 전체선형, 3 물리스케일(V1), 4 핀비율선형(V2 계열).
- 분할 A(주): 시편 LOSO, 정상 9시편(NO2~NO10). 분할 B(참고): CAL(NO2·NO3) 학습 → NO4~NO10 평가(2점이라 선형 기울기는 불안정, 참고로만).
- 주 결과 행: cross50 × (7번에서 정한 방식 3 또는 4) × 분할 A × 전체 이미지.

## 9. E10
- 원 코드(pretrain/finetune/evaluate) 그대로, 래퍼에서 다음만 바꾼다: PHYSICAL_SCALE(4절), V2 계수 10→16, 해석 규칙 기준값.
- 사전학습 증강: shift·밝기·대비만. 하단 블러(σ0.5·1.0)는 10/21에서 검증 안 됐으므로 뺀다.
- fold: 정상 9시편(NO2~NO10, NO9 포함) LOSO + 전체 1회. NG는 전체 모델로 평가만.
- 해석 규칙(고정): ① 평균 찍기 대비 MAE가 동일 장착 기준선(6절) 이상 낮다, ② 9 fold 중 7 fold 이상에서 평균 찍기보다 낮다, ③ 열별 엣지 이동 중앙값 ≤ 1.38px(10/08의 1px = 36.7µm를 µm 기준으로 유지). 셋 다 만족 → "실측 레이블이 정보를 담고 있을 가능성", 아니면 "셋업 잡음을 넘지 못함".
- 주 변형: 7번에서 정한 스케일(V1/V2) 계열 4개를 함께 보고하되, 변형 선택을 MAE로 하지 않는다.

## 10. 최종 질문에 대한 판정
- "평균 찍기 대비 우위": E6 주 결과 행과 E10 주 변형 각각에 대해 9번 ①·② 기준을 적용.
- "NG 방향 일치": 2절의 3단계로 NO11·NO12 각각 기록.
- 한계로 반드시 적을 것: 시편 9+2개, 한 세션, 재장착은 NO7~NO12만, CAL 2점, 드리프트.
