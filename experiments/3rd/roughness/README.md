# E11 표면거칠기 실험 (진행 중)

규칙은 `PREREG_E11.md`, 구현 지시는 `EXPERIMENTS_E11_roughness_for_ClaudeCode.md`. 새 측정 없이 10/21 결과와 캐시만 쓴다. 이 보고서는 단계가 끝날 때마다 채우고, E11-R에서 완성한다. **진행: E11-0 ✔, E11-A ✔, E11-B ✔, E11-C ✔, E11-E ✔, E11-F·E11-R 미완.**

## 0. 결론 (현재까지)

**주 가설(E11-A):** "시편 고유 굴곡은 있으나 Rz와의 관계는 이 데이터로 판단 불가(파상도·진원도·이물 등 다른 원인 가능)." (PREREG 3.6절 문장 2번, n = 11, 탐색)

- 1단계: 시편 고유 반복 성분이 있는 시편 10/11(기준 ≥ 6, 통과. 없는 시편은 NO5). 그러나 크기가 작다. 반복 분산의 대부분은 시편과 무관한 고정 패턴이다.
- 2단계: Spearman ρ(Rz, a_spec_top) = −0.30, 단측 순열 p = 0.83. 거칠수록 굴곡이 크다는 방향의 증거는 없다.
- **사후 민감도 분석(24가지)도 모두 같은 문장 2번이다.** 단, 시편별 판정은 변형에 민감하다: NO3의 고유 성분 판정은 끝열(x = 8265) 제외 또는 within·cross 열 일치(matched)에서 사라지고, 고유 성분 있는 시편 수는 8~11개로 변한다. 시편별 진폭 순위도 사전 등록 순위와 상관 0.65~1.0으로 안정적이지 않다. 따라서 **시편별 진폭 크기와 순위는 해석하지 않는다.**
- 해석 전제: 이미지는 약 0.1mm보다 긴 파장의 굴곡만 보고, 거칠기는 원주 한 위치의 1회 측정이다. n = 11에서 ρ = 0.5 검출력은 약 1/3이라 "관계 없음"이 아니라 "판단 불가"다.

## 1. 데이터와 사전 고정

- 거칠기: `data/roughness_raw.csv`. 대응 NOk→NOk, NG1→NO11, NG2→NO12. 분석 NO2~NO12(n = 11), NO1 제외.
- 이미지 쪽: 10/21 열별 엣지 캐시 `profiles_1021.npz`(저장소 밖, 열별 cross50 = center + label), 본시험(암막) 시편당 10장.
- 규칙(`PREREG_E11.md`)은 결과 전에 `5179fb6`으로 커밋했다. 실행 중 결정과 사후 변경은 부록에 날짜와 함께 있다.

## 2. 단계별 결과

### E11-0 데이터 준비와 재현 확인 (`results/E11_0_checks.csv`)
- (a) 140장 모두 `center + label`의 1차 강건적합이 `bearing_top_y`·`bearing_bot_y`와 일치(최대 차이 0.0px). (c) 평균 찍기·V1·방식4의 정상 9시편 MAE 6.64·8.48·3.99µm 재현.
- (b) 캐시는 89px 창이라 원본 `edge_subpx`의 양쪽 샘플 구간이 온전한 열이 없어 cross50 완전 재현은 검증하지 못했다. 아랫엣지는 평활 적용 시 label과 중앙값 0.006px로 맞고, 윗엣지는 0.077px이며 원인은 미확정이다.
- (d) 시편당 10장. 교집합 열은 NO8만 0(x 격자 홀짝 혼재).

### E11-A 시편 고유 엣지 굴곡 vs Rz (`results/E11A_*.csv`, `figures/E11A_*.png`)
- 사전 등록 추정량: 윗엣지 강건 2차 추세 제거 잔차, split-half 126가지, 고정 패턴 대조(같은 x 격자 시편 4~5쌍).
- 재장착 대조(서술): NO9~NO12의 재장착 lag 0 상관은 약 0(−0.10~0.00), NO7·NO8은 0.38·0.40. 최대 상관의 lag 중앙값이 탐색 범위 끝(±5샘플)에 몰려 있어 부풀려진 값이다.
- 스펙트럼: 8px(JPEG 블록) 주기 대역 파워는 중앙값의 0.9~3.0배로 뚜렷한 피크가 없다.
- **사후 민감도(`E11A_sens_*.csv`, 24변형)**: Codex 리뷰의 세 지적을 확인했다.
  1. within과 cross의 열 집합이 달라 NO3의 판정이 뒤집힌다(matched로 맞추면 S_spec < 0).
  2. NO8만 홀수 격자 이미지를 짝수 격자로 보간해 평활이 비대칭이다. 격자 시작점을 +1px로 바꾸면 S_spec이 약 48% 변한다. NO8을 뺀 변형에서도 결론은 같다.
  3. 오른쪽 끝열(x = 8265)이 NO3·NO7·NO10에서 −50~−67µm로 급락하고, 이 한 열이 NO3의 판정을 바꾼다. 끝열의 밝기 대비는 내부와 비슷해(185~200 vs 약 198) 측정 이상의 증거는 없지만 실제 표면인지도 확정하지 못했다(원영상 확인 필요).
  - 변형 24가지에서 ρ(Rz, a_spec_top) −0.68~+0.02, 단측 p 0.49~0.98.

### E11-B 엣지 선명도 vs Ra (탐색, `results/E11B_*.csv`, `figures/E11B_*.png`)
- 윗엣지 10–90% 폭(주 분석, Gaussian σ1.2 평활 적용)은 시편 간 24~26px(약 620~690µm)이고, ρ(Ra, 폭) = −0.49(단측 p = 0.94, n = 11, 탐색)로 거칠수록 넓다는 방향이 아니다. Rz와는 ρ = −0.76.
- **촬영 순서 교락:** 폭과 촬영 순서의 ρ = +0.85(|ρ| ≥ 0.5 → 촬영 순서(배율 드리프트) 교락 가능). 폭은 촬영 순서대로 늘어난다(NO2 24.3 → NO12 26.5px). 따라서 폭의 시편 간 차이는 거칠기보다 촬영 순서로 설명될 여지가 크다.
- 아랫엣지(보조): 폭 18.7~21.4px, ρ(Ra, 폭) = −0.26. 평활 없는 프로파일(부차)에서도 윗엣지 ρ(Ra, 폭) = −0.55로 같은 방향이다.
- 한계: ESF의 90% 지점이 배경쪽의 완만한 어깨(u ≈ −12px)에 있어 배경 수준 추정에 민감하다. 절대 폭은 해석하지 않고, 이 단계에서 윗엣지 label은 cross50이라 u = 0이 0.5 수준과 정확히 겹치도록 평활을 맞췄다.

### E11-C 라벨 불확도 상한과 what-if (계산, `results/E11C_*.csv`, `figures/E11C_pass_prob_vs_c.png`)
- 재현: 평균 찍기·V1·방식4 정상 9시편 MAE 6.64·8.48·3.99µm(assert 통과).
- **상한(5.1절):** 방식4 오차 RMSE 5.15µm(시편 부트스트랩 95% 구간 2.81~7.15), RMS(Rz) 11.03µm → c_max = 0.47(0.26~0.65). 평균 찍기 0.72, V1 1.08은 참고(구간이 넓다).
- **what-if(5.2절):** PREREG 격자(c ≤ 0.50)에서는 완벽 측정기도 규칙 ①②를 통과할 확률이 50% 아래로 내려가지 않는다(c = 0.50에서 54%). 사후 확장 격자에서 교차점은 c ≈ 0.56이다. 상한 c ≤ 0.47(95% 구간 0.26~0.65)과 점추정으로는 겹치지 않고, 구간의 위쪽 끝(0.65)에서만 닿는다.
  - sd = c·Rz 및 σ_m = 5.2·6.4µm(NO7~NO12 재장착의 장착별 표준편차 중앙값) 가정에서는 재장착 수준 측정기의 ①② 통과 확률이 c와 무관하게 6~26%로 낮다. 이는 가정한 모형에 조건부인 결과이며 **실제 병목은 미확정**이다. σ_m은 정상 9시편의 평가 단위(전체 이미지 중앙값·보정 예측의 오차)로 검증하지 않았고, 잡음 모형·σ_m 민감도 분석은 하지 않았다.
- 해석 한계: 상한은 측정 오차와 라벨 잡음이 독립이라는 가정에서만 성립하고, 라벨 잡음이 Rz에 비례한다는 모형은 가정이다(거칠기와 마이크로미터 오차의 관계는 측정한 적이 없다). 확장 격자는 결과를 본 뒤 추가한 사후 변경이다.

### E11-E 오차 vs 거칠기 (반증 기록, **확인용: 결과 일부를 사전에 봄**, `results/E11E_*.csv`)
- **결론: 거칠기로 설명되지 않음(확인용).** 방식4(핀비율 선형)에 Rz 항을 더하면 LOSO MAE가 3.99 → 4.71µm로 오히려 나빠지고(개선 −0.72µm, 기준 +2.92µm), Rz 항이 낮은 fold는 4/9(기준 7/9)다. 방식4 단독 3.99µm 재현 확인.
- 정상 9시편 상관(Spearman, 양측 순열 p): 방식4 오차 vs Rz는 부호 있는 오차 ρ −0.27(p 0.50)·절댓값 +0.25(p 0.52), vs Ra는 +0.07(0.87)·+0.38(0.31). V1 오차 vs Rz는 +0.43(0.25)·0.00(1.00), vs Ra는 +0.13(0.75)·+0.03(0.95). 어느 것도 유의 방향이 아니다(탐색).
- **사전에 본 ρ의 정체:** PREREG 0절의 "Rz–V1 오차 ρ = +0.62, p ≈ 0.05" 등은 NG 2개를 포함한 n = 11, 부호 있는 오차의 값이다(재현 확인, 네 값 일치). 정상 9시편으로 줄이면 같은 관계가 +0.43(p 0.26)으로 약해진다. 즉 사전에 본 약한 연관은 NG 시편(표본 밖 예측)이 끌고 있었다.
- 촬영 순서: V1 부호 있는 오차와 촬영 순서의 ρ = −0.80으로, V1 오차는 거칠기보다 촬영 순서와 더 강하게 움직인다(순서 통제 부분 ρ는 Rz +0.30, Ra +0.11; 부분 ρ의 p는 근거가 부족해 내지 않았다). 이 값들도 n = 9 탐색이다.
- 한계: n = 9에서 Rz 항(파라미터 3개를 8점에 적합)은 과적합하기 쉽다. 이 단계는 "거칠기가 오차를 설명한다"는 가설을 지지하지 않는다는 기록이며, 설명하지 않는다는 증명이 아니다.

## 3. 한계

- 시편 11개(오차 분석은 9개), 한 세션, 거칠기는 시편당 1회·1위치 측정. 이미지가 보는 것은 장파장 성분뿐이다.
