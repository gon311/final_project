# E11 표면거칠기 — 이미지로 거칠기가 보이는가, 오차를 설명하는가

- 작성: 2026-10-27 · 규칙: `PREREG_E11.md`(결과 전에 `0b363dd`으로 커밋, 부록에 실행 중 결정·사후 변경 기록) · 구현 지시: `EXPERIMENTS_E11_roughness_for_ClaudeCode.md`
- 질문: 10/21 사진에서 시편별 표면거칠기(Ra·Rz)가 보이는가, 그리고 거칠기가 치수 오차(라벨 잡음 포함)를 설명하는가.
- **새 측정·재촬영 없이 기존 데이터만 썼다.** 10/21 결과 CSV와 열별 엣지 캐시만 읽었고 원본 이미지는 디코딩하지 않았다.

## 0. 결론

**주 가설(E11-A, 사전 등록 하나뿐):** "시편 고유 굴곡은 있으나 Rz와의 관계는 이 데이터로 판단 불가(파상도·진원도·이물 등 다른 원인 가능)." (PREREG 3.6절 문장 2번, n = 11, 탐색)

1. **E11-A:** 시편 고유 반복 성분이 있는 시편은 10/11(기준 ≥ 6)이지만 크기가 작고 반복 분산의 대부분은 시편과 무관한 고정 패턴이다. Spearman ρ(Rz, a_spec_top) = −0.30, 단측 순열 p = 0.83으로 거칠수록 굴곡이 크다는 방향의 증거는 없다. **사후 민감도 24가지도 모두 같은 문장 2번**이지만 시편별 고유 성분 판정(NO3)과 진폭 순위는 변형에 민감하다(고유 성분 시편 수 8\~11, 진폭 순위 상관 0.65\~1.0). **시편별 진폭 크기·순위는 해석하지 않는다.** 해석 전제: 이미지는 약 0.1mm보다 긴 파장의 굴곡만 보고, 거칠기는 원주 한 위치의 1회 측정이다. n = 11에서 ρ = 0.5의 검출력은 약 1/3이라 "관계 없음"이 아니라 "판단 불가"다.
2. **E11-C(계산, 가설 검정 아님):** 방식4 오차 RMSE 5.15µm에서 본 라벨 잡음 계수의 상한은 c_max = 0.47(시편 부트스트랩 95% 구간 0.26\~0.65)이다. PREREG 격자(c ≤ 0.50)에서는 **완벽 측정기도 규칙 ①②를 통과할 확률이 50% 아래로 내려가지 않는다**(c = 0.50에서 54%). 사후 확장 격자에서 교차점은 c ≈ 0.56이라 상한 점추정(0.47)과는 겹치지 않고 구간의 위쪽 끝(0.65)에서만 닿는다. 즉 점추정 기준으로는 상한(0.47)이 교차점(0.56)보다 작아 겹치지 않지만, 상한의 95% 구간(0.26\~0.65)과는 겹치므로(구간 안의 c = 0.60에서 완벽 측정기 통과 확률 47%) **라벨 잡음만으로 판정이 막힐 가능성은 배제하지 못한다**(교차점은 사후 확장 격자의 보간 결과이고, 잡음 모형 sd = c·Rz는 가정이다).
3. 나머지는 **탐색·확인용**이다.
   - E11-B(탐색): 윗엣지 10–90% 폭과 Ra의 ρ = −0.49(단측 p 0.94)로 거칠수록 넓다는 방향이 아니고, 폭은 촬영 순서와 ρ = +0.85라 **촬영 순서(배율 드리프트) 교락 가능**이다.
   - E11-E(확인용, 결과 일부를 사전에 봄): 방식4에 Rz 항을 더해도 LOSO MAE가 3.99 → 4.71µm로 나빠진다. "거칠기로 설명되지 않음"(증명이 아니라 지지하지 못했다는 기록).
   - E11-F(서술): 재장착 σ의 시편 간 중앙값 5.18µm(원시)·6.36µm(핀 비율)을 재현했고, Rz와 나란히 낸 n = 6 표이며 관계는 판단하지 않는다.

## 3. 사후 관찰 (사전 등록 밖 — 결론에 쓰지 않고 다음 촬영·다음 분석의 근거로만)

실행 중 결정과 사후 변경은 모두 `PREREG_E11.md` 부록에 날짜와 함께 있다. 아래는 결과를 본 뒤의 변경·관찰이다.

1. **E11-A 사후 민감도(24변형):** Codex 리뷰의 세 지적(within·cross 열 집합 불일치, NO8만 보간 평활, 오른쪽 끝열이 잔차에 남음)을 확인했다. NO3의 고유 성분 판정이 끝열 제외·matched에서 사라지고, NO8의 격자 시작점을 +1px로 바꾸면 S_spec이 약 56%(진폭 a_spec은 약 25%) 변한다. 결론 문장은 24가지 모두 같다(ρ −0.68\~+0.02, 단측 p 0.49\~0.98).
2. **끝열(x = 8265) 급락 → 사진 쪽 고정 패턴(원영상 확인, 2026-10-27):** NO3·NO7·NO10의 오른쪽 끝열이 −50\~−67µm로 급락한다. 원본 사진(EXIF 180° 회전 적용)에서 윗엣지를 1px 열 단위로 추적하니 x = 8265\~8266에 3\~5열 폭의 좁은 스파이크(깊이 14\~62µm)가 있고 그 바깥은 매끄럽게 이어진다. 이 스파이크는 NO8을 뺀 10개 시편에 모두 같은 열에 나타난다(`E11A_endspike.csv`, 시편당 5장). 시편마다 표면과 장착이 달라 실제 표면이면 같은 열에 생길 수 없으므로 **측정 구간 끝에 걸린 사진 쪽 고정 위치 아티팩트**로 본다. NO3·NO7·NO10만 지적된 것은 측정 구간이 이 열에서 끝났기 때문이다(NO5는 8258에서 끝나 피했다). 아랫엣지에는 같은 위치의 스파이크가 없다(최대 편차 열이 8254\~8283으로 흩어짐). 따라서 "끝열 제외" 변형(NO3의 고유 성분 판정이 사라짐)이 맞는 분석이고, 원 결과의 NO3 판정은 신뢰하지 않는다. 한계: 센서·렌즈·JPEG 중 원인은 가리지 못했고, 재장착·암막없음 사진과 시편당 5장 이후는 보지 않았다.
3. **E11-C 사후 확장 격자:** PREREG 격자만으로는 "c ≥ ○○" 문장을 채울 수 없어 c = 0.6\~1.0을 추가했다.
4. **E11-E 부분상관 p 삭제:** 순위 잔차를 직접 순열한 p가 부적절해 삭제했다(부분 ρ는 유지). 난수 소비 순서가 바뀌어 `p_two_sided`가 최대 0.011 달라졌다(몬테카를로 오차 범위).
5. **E11-B 촬영 순서 교락, E11-E V1 오차–촬영 순서:** 폭(ρ +0.85)과 V1 오차(ρ −0.80) 모두 거칠기보다 촬영 순서와 강하게 움직인다. 10/21 보고서의 배율 드리프트(핀 px −0.19%)와 같은 방향의 관찰이다.

## 4. 한계

- 시편 11개(오차 분석은 9개), 한 세션, 거칠기는 시편당 1회·1위치 측정. 측정 각도(원주 위치)는 기록이 없고, 사진의 윗엣지·아랫엣지는 다른 원주 위치일 수 있다.
- 이미지가 보는 것은 약 0.1mm보다 긴 파장의 표면 굴곡뿐이다(열 간격 52µm, 열마다 3px 평균). 거칠기(Ra·Rz)는 이보다 짧은 파장까지 포함하므로 E11-A는 거칠기 전체가 아니라 장파장 성분(파상도 쪽)이 Rz 순서와 함께 움직이는지만 본다.
- E11-E는 결과 일부를 이미 본 뒤의 확인이다.
- 새 측정 없이 기존 데이터만 썼다.
- 추가로: 캐시가 89px 창이라 원본 cross50의 완전 재현은 검증하지 못했다(E11-0 (b)). E11-A 민감도 24변형은 서로 독립이 아니다. E11-C의 상한은 측정 오차와 라벨 잡음이 독립이라는 가정에, what-if는 sd = c·Rz와 σ_m = 5.2·6.4µm 가정에 의존한다.

## 5. 다음 촬영·다음 분석 제안 (결과에서 나온 것만)

1. **마이크로미터 다점 측정:** 라벨 잡음 상한(c_max 0.26\~0.65)이 넓고 잡음 모형(sd = c·Rz)이 가정이라, 라벨 자체의 불확도를 직접 재야 한다(E11-C). 같은 시편의 여러 위치·각도를 재서 라벨 잡음과 거칠기의 관계를 측정한다.
2. **시편 순서 무작위화와 기준 시편 반복 촬영:** E11-B의 폭(촬영 순서와 ρ +0.85)과 E11-E의 V1 오차(ρ −0.80)가 거칠기와 촬영 순서를 분리하지 못한다. 순서를 섞고 기준 시편을 시작·중간·끝에 반복해 드리프트와 시편 효과를 나눈다.
3. **거칠기 측정 위치·각도 기록과 다점 측정:** 거칠기가 1위치 1회 값이고 각도 기록이 없어, 사진의 엣지 위치와 대응이 불명확하다(한계 1). 사진 구간과 같은 원주 위치에서 여러 번 재고 위치를 기록한다.
4. **끝열 제외 후 E11-A 주 결과 재산출:** 끝열 급락은 아티팩트로 확인됐으므로(3절 2번) x ≥ 8260을 뺀 결과를 주 결과로 다시 낼지 정한다(재촬영 불필요). 다음 촬영에서는 측정 구간이 x = 8265 부근에서 끝나지 않게 한다.
5. **시편 수 확대:** n = 11에서 ρ = 0.5의 검출력이 약 1/3이라 "판단 불가"가 남았다. 시편을 늘려야 판정이 가능하다.
