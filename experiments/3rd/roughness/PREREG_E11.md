### 1.3 해석상 전제 (결론에 같이 적을 것)

- 이미지가 볼 수 있는 것은 **약 0.1mm보다 긴 파장의 표면 굴곡**뿐이다. 열 간격이 52µm이고 열마다 3px(78µm)를 평균했기 때문이다. 거칠기 측정(Ra·Rz)은 이보다 짧은 파장까지 포함한다. 따라서 E11-A는 "거칠기 전체"가 아니라 **거칠기 중 장파장 성분(파상도 쪽)이 Rz 순서와 함께 움직이는지**를 본다.
- 거칠기는 원주의 한 위치에서 잰 값이다. 사진의 윗엣지·아랫엣지는 다른 원주 위치일 수 있다. 원주 방향으로 표면이 균일하다고 가정한다.
- n = 11이면 Spearman ρ = 0.5를 검출할 확률이 약 1/3이다. 유의하지 않은 결과는 "관계 없음"이 아니라 **"이 데이터로는 판단 불가"**로 쓴다.

## 2. 주 가설과 다중검정

- **주 가설은 E11-A 하나다:** "같은 장착 안에서 반복되는 **시편 고유** 윗엣지 굴곡의 크기는 Rz가 클수록 크다."
- 주 판정 통계: Spearman ρ(Rz, `a_spec_top`), **단측(양의 방향)** 순열 p, 순열 10000회, 시드 42, n = 11. 유의 수준 0.05.
- 나머지(E11-A 보조 지표, E11-B·C·E·F)는 모두 **탐색·서술**이다. p값은 적되 "유의"라는 표현을 쓰지 않는다.
- 거칠기 지표는 미리 정한다: E11-A = **Rz**, E11-B = **Ra**. 다른 지표(Ra↔Rz 교차, Rz/Ra)는 보조 표로만 낸다.

## 3. E11-A 시편 고유 엣지 굴곡 (주 가설)

### 3.1 데이터
- 본시험(암막) 각 시편 10장. 같은 장착이다. 재장착 사진은 3.5절 보조 분석에만 쓴다.

### 3.2 잔차 프로파일
1. 이미지마다 윗엣지 열별 위치 `y_j = top_center + top_label`을 구한다.
2. 이미지마다 **강건 2차 다항식**(원 코드 `robust_fit`과 같은 방식: 1차 적합 → |r| < 4·1.4826·MAD 밖 제외 → 2차 재적합)으로 추세를 뺀다. 잔차 `r_j`를 쓴다.
   - 보조: 1차 직선 추세 제거 결과도 계산하되 판정에는 쓰지 않는다.
3. 같은 시편 10장의 공통 x 격자 = 10장 모두에 있는 절대 x의 교집합. 홀짝이 어긋나 교집합이 원래 열 수의 80% 미만이면 2px 격자로 선형 보간한다(보간했는지 기록).
4. 아랫엣지도 같은 방법으로 계산해 **보조**로 낸다.

### 3.3 Split-half
- 10장을 5장·5장으로 나누는 126가지를 **모두** 쓴다.
- 나눔마다 각 묶음의 열별 평균 잔차 A, B를 만든다. 다음을 계산한다.
  - `r_AB` = Pearson 상관(열 방향)
  - `S_within` = cov(A, B) (px²). 잡음이 서로 독립이면 반복 성분의 분산을 추정한다.

### 3.4 고정 패턴 대조 (핀 대신)
- 센서·렌즈·JPEG 블록 같은 **이미지 좌표에 고정된 패턴**은 시편과 관계없이 모든 시편에 같은 x 위치로 나타난다.
- 시편 p의 5장 평균과 다른 시편 q의 5장 평균을 같은 절대 x에서(lag 0) 비교한다. `S_cross(p,q)` = cov, `r_cross(p,q)` = 상관이다. 각 시편 쌍에서 나눔 126가지 중 50가지를 고정 시드(42)로 뽑아 중앙값을 쓴다.
- **시편 고유 분산:** `S_spec(p)` = median over splits[S_within(p)] − median over q≠p[S_cross(p,q)]
- **시편 고유 진폭:** `a_spec(p)` = sqrt(max(S_spec(p), 0)). px와 µm 둘 다 적는다.

### 3.5 보조: 재장착 대조 (NO7~NO12, 서술만)
- "본시험 9장 평균 vs 본시험 남은 1장"의 상관(10가지 평균)과 "본시험 10장 평균 vs 재장착 1장"의 상관(5회 평균)을 비교한다.
- 재장착 쪽은 lag 0과 ±10px 안의 최대 상관을 둘 다 적는다. 최대 상관은 고르는 과정이 있어 부풀려진다는 점을 함께 적는다.

### 3.6 판정 (고정)
- **1단계: 시편 고유 반복 성분이 있는가.** 시편마다 나눔 126가지에서 `S_within − median S_cross`의 5퍼센타일이 0보다 크면 "그 시편에 고유 성분 있음"이다. 11개 중 **6개 이상**이면 1단계 "있음"이다.
- **2단계: Rz 순서를 따르는가.** 2절의 주 판정 통계를 쓴다.
- 결론 문장(셋 중 하나):
  1. 1단계 있음 + ρ > 0 + p < 0.05 → "사진 윗엣지의 시편 고유 굴곡이 Rz 순서를 따른다. 거칠기의 장파장 성분이 사진에 보일 가능성(n = 11, 탐색)."
  2. 1단계 있음 + 그 밖 → "시편 고유 굴곡은 있으나 Rz와의 관계는 이 데이터로 판단 불가(파상도·진원도·이물 등 다른 원인 가능)."
  3. 1단계 없음 → "이 셋업 해상도에서 표면 굴곡은 측정 잡음·고정 패턴 아래에 있다."
- 어느 경우든 1.3절 전제를 함께 적는다.

## 4. E11-B 엣지 선명도 vs Ra (탐색)

- 본시험 10장, 윗엣지(주)·아랫엣지(보조).
- 열마다 캐시 프로파일을 cross50 위치 기준으로 정렬한다(선형 보간, 0.1px 격자, 엣지 기준 ±30px).
- 양쪽 25~40px 떨어진 구간의 중앙값으로 0(물체)~1(배경)로 정규화한다.
- 시편마다 모든 열·10장을 평균해 ESF를 만든다. 다음을 계산한다.
  - 10–90% 폭(서브픽셀, 선형 보간)
  - 최대 기울기
- 통계: Spearman ρ(Ra, 윗엣지 10–90% 폭), 단측(양: 거칠수록 넓다) 순열 p.
- **교락 점검:** 같은 폭 지표와 촬영 순서(본시험 시작 시각 순위)의 ρ를 함께 적는다. |ρ| ≥ 0.5면 "촬영 순서(배율 드리프트) 교락 가능"을 결론에 붙인다.
- 캐시 프로파일에는 원 코드의 Gaussian 평활(σ1.2)이 들어 있을 수 있다. 모든 시편에 같이 적용되므로 순위 비교에는 영향이 없다고 보고, 절대 폭은 해석하지 않는다.

## 5. E11-C 라벨 불확도 상한과 what-if (계산, 가설 검정 없음)

- 대상: 정상 9시편(NO2~NO10), E6 cross50 · 전체 이미지 · 분할 A(시편 LOSO).
- **재현 확인:** 평균찍기 MAE 6.64, V1 8.48, 방식4 3.99µm. 다르면 멈추고 보고한다.

### 5.1 상한
- 방식4 시편별 오차의 RMSE를 라벨 잡음 σ_L의 상한으로 쓴다(측정 오차와 라벨 잡음이 독립이면 σ_L ≤ RMSE).
- 시편 단위 부트스트랩 2000회(시드 42)로 RMSE의 95% 구간을 낸다.
- `c_max = RMSE_방식4 / RMS(Rz, 9시편)`도 적는다.

### 5.2 What-if
- 라벨 잡음 ε_i ~ N(0, (c·Rz_i)²), c ∈ {0, 0.05, 0.10, 0.15, 0.20, 0.30, 0.40, 0.50}.
- 엑셀 실측값을 "참값"으로 두고 관측 라벨 = 참값 + ε로 만든다. 10000회, 시드 42.
- 측정기 두 가지:
  - (a) **완벽 측정기:** 예측 = 참값.
  - (b) **재장착 수준 측정기:** 예측 = 참값 + δ, δ ~ N(0, σ_m²). σ_m은 5.2µm(원시)와 6.4µm(핀 비율 보정) 둘 다 쓴다(10/21 PREREG 부록 값).
- 비교 대상: 같은 관측 라벨로 계산한 평균 찍기 LOSO.
- 반복마다 10/21 규칙을 그대로 적용한다.
  - ① MAE 개선 ≥ 2.92µm
  - ② 9 fold 중 7 이상 승
- c별로 다음을 표로 낸다: ①②를 함께 통과할 확률, 측정기 MAE 중앙값, 평균 찍기 MAE 중앙값.
- 결론 형식: "c ≥ ○○이면 완벽 측정기도 규칙 ①②를 통과할 확률이 50% 미만이다. 상한(5.1절)으로 본 c의 가능 범위는 ≤ ○○이다." 두 범위가 겹치는지를 쓴다.

## 6. E11-E 오차와 거칠기 (반증 기록, 일부 결과를 이미 봄)

- 정상 9시편. V1·방식4 시편별 오차 vs Rz, Ra.
  - Spearman ρ와 양측 순열 p
  - 촬영 순서를 통제한 부분 Spearman: 오차·거칠기 각각의 순위를 촬영 순서 순위에 회귀한 잔차끼리의 Pearson
- LOSO 비교: `mm = a + b·(16·D/pin_px)` (방식4) vs `mm = a + b·(16·D/pin_px) + g·Rz`. fold마다 학습 8시편으로 맞춘다.
- 판정(고정): Rz 항이 MAE를 **2.92µm 이상** 줄이고 **9 fold 중 7 이상**에서 낮으면 "거칠기가 오차 일부를 설명할 가능성", 아니면 "거칠기로 설명되지 않음".
- 0절에 적은 대로 이미 본 결과가 있으므로, 결론에 "확인용"이라고 적는다.
