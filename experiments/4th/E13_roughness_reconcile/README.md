# E13 거칠기 분석 재현·조정 — 선행개발자님 분석과 E11-A는 왜 반대 부호인가

> 규칙: `docs/PREREG_E13.md`(실행 전 고정). 새 측정·재촬영 없음, 원본 사진 디코딩 없음(E11 캐시와 10/21 CSV만). 모든 결과는 탐색·서술이며 n = 11이다.

## 0. 결론

**선행개발자님의 양의 상관은 우리 엣지 데이터(전체 11시편)로 재현되지 않는다. 차이는 엣지 추출·창·시편 선택의 차이로 보인다(탐색, n = 11).** (PREREG 7절 문장 B: 재현 행의 Pearson r(Rq, MAD) = +0.13 < 0.30)

1번 이미지 하단 엣지 산포의 주성분은 혼합이다(11시편 몫 중앙값 S 0.12, F 0.34, N 0.49).

E11의 결론(주 가설 문장 2번)은 바뀌지 않는다. E13은 새 검정이 아니라 재현·조정이다.

- 대표 수치(대표 행 C-cols-poly1-10, MAD vs Rq): Spearman ρ +0.12, 양측 순열 p 0.74, Pearson r +0.03.

## 1. 데이터와 사전 고정

- 본시험 NO2\~NO12 110장(시편당 10장), 하단 `y_bot`, 거칠기는 `roughness_clean.csv`의 Ra·Rq·Rz. 1번 이미지 = 시편별 시각이 가장 빠른 사진.
- 창 H(선행개발자님 재현: x 8090.67\~8224), 창 C(좌 2mm·우 3mm, 1번 이미지 c 기준), 창 C_rev(좌우 반전). 모든 규칙은 PREREG 2\~8절에 실행 전 고정했고, 실행 중 결정은 PREREG 부록에 있다.
- E13-0 점검: 1번 이미지·c·격자 홀짝·창 열 수 모두 PREREG 표와 같다. E11 정합(NO8 제외 10시편): R vs `S_within_med` ρ 0.99, 비 중앙값 1.00 / F vs `S_cross_med` ρ **0.76**(기대치 ≥ 0.8에 미달), 비 중앙값 1.01. 정의는 바꾸지 않았다.

## 2. 단계별 결과

- NO2는 대체로 비슷(0.46\~0.61 vs 0.573), NO9·NO10은 우리 값이 선행개발자님 값(0.811, 0.930)의 절반 안팎이고 순서도 자주 뒤바뀐다. STD·Range도 같은 경향.

## 3. 사후 관찰 (사전 등록 밖 — 결론에 쓰지 않음)

- **MAD–Rq의 1장 양의 상관이 10장에서는 사라진다.** cols를 쓰는 H-none·C-none·C-poly1 조건에서 1번 이미지 한 장은 ρ +0.44\~+0.57(r +0.42\~+0.47, 선행개발자님의 +0.50과 같은 크기), 10장 지표 중앙값은 ρ −0.03\~+0.12(r −0.02\~+0.03). pts 14점인 재현 행은 1장에서도 r +0.13이다. Range·STD는 1장에서도 Rq와 음의 상관(C-cols-poly1-1: Range r −0.82, STD r −0.52)이라 산포 전반으로 일반화할 수 없다. 한 장 산포의 큰 몫이 장마다 다른 잡음(N)·고정 패턴(F)이라는 E13-2와 같은 방향이지만, 이것이 원인이라는 증거는 아니다.
- 재현 실패의 원인은 모른다. 스케일(10.2mm = 272px)은 px 지표에 영향이 없고, 1번 이미지 선택도 같다. 평활 정도가 다른 엣지 검출이 유력한 미확인 후보다.

## 4. 한계

- 시편 11개, 한 세션, 거칠기는 시편당 1회·1위치 측정. 같은 시편의 업체 첫 측정 3개와 재측정이 다르다(NO10 Rz 8.1 → 16.4µm). 거칠기 라벨 자체가 위치에 따라 흔들린다.
- 선행개발자님의 엣지 검출 방법·안정군 기준·Raw CV 정의를 모른다. 재현은 근사다.
- 우리 엣지는 3열 평균·평활된 cross50이다. 이미지는 약 0.1mm보다 긴 파장의 굴곡만 본다.
- E11 결과와 선행개발자님 결과를 모두 본 뒤의 분석이다. E11 정합 점검에서 ρ(F) 0.76으로 기대치에 약간 못 미쳤다.

## 5. 팀 공유용 요약

1. 선행개발자님의 수치(NO2·NO9·NO10 엣지 산포)를 우리 데이터로 다시 계산했으나 같은 값이 나오지 않았다. 엣지를 잡는 방법 차이로 보이며 원인은 확인되지 않았다.
2. 사진 한 장의 엣지 산포는 절반 가까이 장마다 달라지는 잡음, 3분의 1은 시편과 무관한 고정 패턴이고, 시편 고유 성분은 약 12%뿐이다.
3. cols를 쓰는 조건에서 MAD만 보면 한 장 기준 Rq와 r ≈ +0.42\~+0.47이지만, 10장 중앙값에서는 r ≈ 0이다. Range·STD는 한 장에서도 Rq와 음의 상관이고 재현 행(pts)도 r +0.13이라 "거칠수록 산포가 크다"고 일반화할 수 없다. 거칠기와의 관계는 이 데이터로 판단하기 어렵다.
4. 스케일 정정: 272px는 10.2mm가 아니라 실제 약 7.1mm이고, "5mm" 창 133px은 실제 약 3.5mm다(0.026092 mm/px).
5. E11의 결론은 바뀌지 않는다. 두 분석의 부호 차이는 한 장 기준과 시편 고유 성분 기준이라는 지표 차이로 일부 설명된다.
